2. GPS 기반 근거리 매칭 프로토콜 규격

방 생성 및 근거리 필터링 조회를 위해 시그널링 서버와 브라우저가 통신할 때 사용하는 위치 패킷 포맷 및 거리 연산 방법입니다.

위치 정보 구조체 (Geolocation Schema)

interface UserLocation {
  latitude: number;   // 위도
  longitude: number;  // 경도
  accuracy: number;   // GPS 오차 범위 (미터 단위)
}

interface RoomRegistration {
  peerId: string;
  hostName: string;
  gameId: string;
  location: UserLocation;
  timestamp: number;
}

반경 연산 공식 (Haversine Formula)

시그널링 서버는 호스트와 게스트의 좌표 정보를 기반으로 두 구체 좌표 간의 거리를 계산하여 20m 이내 목록만 반환합니다.

// 하버사인 수학 계산식 (서버 구현용)
const R = 6371e3; // 지구 반경 (미터)
const phi1 = lat1 * Math.PI/180;
const phi2 = lat2 * Math.PI/180;
const deltaPhi = (lat2-lat1) * Math.PI/180;
const deltaLambda = (lon2-lon1) * Math.PI/180;

const a = Math.sin(deltaPhi/2) * Math.sin(deltaPhi/2) +
          Math.cos(phi1) * Math.cos(phi2) *
          Math.sin(deltaLambda/2) * Math.sin(deltaLambda/2);
const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));

const distance = R * c; // 계산된 최종 거리 (미터 단위)

3. WebRTC 연결 불안정 및 재연결 패킷 규격

기기가 멀어지거나 환경 요인으로 DataChannel이 끊겼을 때 자동 재설정을 지원하기 위한 프로토콜 패킷입니다.

// 재연결 및 이탈 프로토콜 메시지 유형
type ReconnectType = 
  | 'RECONNECT_REQUEST'  // 핑 단절 시 재연결 타겟 확인용
  | 'RECONNECT_ACK'      // 재연결 성공 승인
  | 'HEARTBEAT'          // RTT 측정을 위한 주기적 신호 (1초에 1회)
  | 'GPS_ALERT';         // 위상 거리 한계 임계점 도달 경고 전달

interface ReconnectPacket {
  type: ReconnectType;
  lastSequence: number;  // 동기화를 맞추기 위한 게임 마지막 액션 번호
  timestamp: number;
}

하트비트 & GPS 얼럿 핸들링

  • 1초마다 기기 간 HEARTBEAT 패킷 교환.
  • RTT 값이 300ms 초과하거나 GPS 수치가 25m 이상 차이 나면 상대방 단말에 GPS_ALERT 발송해 화면 경고 가이드 출력.

세션 재수립 동작

  • 물리 단절 시 DataConnection 재생성 시도.
  • 양측 lastSequence 값을 비교하여 유실된 게임 패킷이 있는 경우 재전송 후 동기화 재개.

4. 서비스 워커 및 웹 푸시 알림 등록 명세

배경 오프라인 캐싱 처리 및 Web Push 수신을 위한 sw.js 내 핵심 리스너 설계 가이드입니다.

// sw.js 핵심 캐싱 및 푸시 이벤트 리스너
const CACHE_NAME = 'minidamo-v1';
const ASSETS_TO_CACHE = [
  '/',
  '/index.html',
  '/src/main.tsx',
  '/src/styles/global.css',
  '/src/styles/variables.css',
  '/public/manifest.json'
];

// 1. 설치 단계: 에셋 프리캐싱
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(ASSETS_TO_CACHE))
  );
});

// 2. 패치 단계: 캐시 우선 대응 (오프라인 지원)
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((cachedResponse) => {
      return cachedResponse || fetch(event.request);
    })
  );
});

// 3. 푸시 알림 이벤트 수신
self.addEventListener('push', (event) => {
  const data = event.data ? event.data.json() : { title: 'minidamo', body: '게임 초대 요청이 있습니다.' };
  
  const options = {
    body: data.body,
    icon: '/public/icons/icon-192.png',
    badge: '/public/icons/icon-72.png',
    vibrate: [100, 50, 100],
    data: { url: data.url }
  };

  event.waitUntil(
    self.registration.showNotification(data.title, options)
  );
});
