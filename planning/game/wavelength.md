# 냥파장 (가칭) — 기획 정리서

> 2~8인 감각 대전. 촉냥(출제자)만 스펙트럼 위 숨은 지점을 보고, 그 지점을 단서 한 줄로 전한다. 나머지는 단서만 듣고 다이얼을 돌려 그 지점을 맞춘다. 논리가 아니라 **"쟤는 이걸 어디쯤으로 느낄까"**를 읽는 게임. 사람이 많을수록 재밌지만, 2인은 협력 모드로 즐긴다.

_가칭 후보: 냥파장 / 촉냥 / 텔레파시냥_
_(추리·순발력·심리·기억과 또 다른 '감각 캘리브레이션' 축. AI 없이 사람이 단서를 만들고, 시스템은 스펙트럼 카드 뱅크 + 랜덤 지점 + 거리 계산만 함)_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 촉냥의 단서만 듣고, 숨은 지점에 다이얼을 최대한 **가깝게** 맞춰라.

### 화면

- 양 끝이 반대인 **스펙트럼 바**(0% ~ 100%)와 돌릴 수 있는 **다이얼**.
- 정답 지점(점수 존)은 **촉냥만** 보임. 나머지에겐 안 보임.

### 역할 (매 라운드 로테이션)

- **촉냥(출제자):** 숨은 지점을 보고 **단서 한 줄** 제시.
- **나머지:** 단서 듣고 각자 다이얼로 지점 추측 → 동시 공개.

### 카드 2종류

| 종류 | 예시 | 촉냥이 하는 일 |
| --- | --- | --- |
| **개념형** | `순하다 ↔ 사납다` | 그 지점 느낌을 자유 단서로 표현 |
| **지표형** | 주제 `음식` · 지표 `매운 정도` | 그 주제 안에서 그 지점에 맞는 **구체적인 걸** 제시 (예: 60%면 "김치찌개") |

### 점수

- 정답 지점과 가까울수록 고득점(정중앙 4점 / 근접 3점 / 애매 2점 / 빗나감 0점).
- **오차 허용 폭은 방에서 설정**(빡빡/보통/널널).

### 승리

- 방에서 고른 조건대로: **먼저 목표 점수** / **정해진 라운드 후 최고점** / **몇 세트 선취**.
- 협력 모드: 팀이 힘 합쳐 목표 점수 달성 = 클리어.

### 핵심 감각

- 촉냥은 "다들 이걸 어디쯤으로 느낄까"를 상상해 단서를 고른다.
- 추측자는 "촉냥이라면 이 단서를 어디에 놓았을까"를 역으로 읽는다.
- 정답이 없는 주관 지표라, 그 **어긋남 자체가 재미**.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2~8인**(권장 4+). **2인은 협력 모드 권장**(경쟁은 촉냥이 상대 점수를 만들어주는 꼴이라 이해 상충이 없어 심심함 → 둘이 팀으로 목표 점수 달성).
- 시드 기반으로 카드 순서·정답 지점을 결정(재접속·공정성). 정답 지점은 매 라운드 **0~100% 랜덤**.

### 카드 시스템

**① 개념형 (양극 대립축)**
- `안 귀엽다 ↔ 개귀엽다`, `흔하다 ↔ 희귀하다`, `유치하다 ↔ 힙하다` 등.
- 촉냥은 자유 단서(단어·짧은 구)로 지점을 표현.

**② 지표형 (도메인 × 지표 매트릭스)**
- **도메인**과 **지표**를 조합해 카드를 만든다. 리스트 두 개 + 궁합표에서 수십 장이 나옴.
- 촉냥은 그 도메인 안에서 정답 지점에 맞는 **구체 인스턴스**를 제시(예: `여행지·인지도` 30%면 살짝 마이너한 여행지).

**도메인 (15)**
음식 · 간식/음료 · 동물 · 곤충 · 영화/드라마 · 노래 · 연예인/인물 · 여행지/장소 · 앱/서비스 · 운동 · 게임 · 직업 · 취미 · 물건/가전 · 패션/브랜드

**지표 (10) → 커버 도메인**

| 지표 | 붙는 도메인 |
| --- | --- |
| 선호도(호불호) | 전 도메인 |
| 인지도(유명도) | 영화·노래·연예인·여행지·앱·게임·패션·물건 |
| 빈도(자주 접함) | 음식·간식·앱·운동·게임·취미·여행지 |
| 비쌈(고가 체감) | 음식·간식·여행지·물건·패션·취미·게임 |
| 무서움 | 동물·곤충·영화·여행지 |
| 힘듦/난이도 | 운동·직업·게임·취미 |
| 건강함 | 음식·간식·운동 |
| 귀여움 | 동물·물건·패션 |
| 유용함 | 앱·물건·취미·직업 |
| 중독성 | 게임·앱·음식·간식·노래 |

- 시스템은 **궁합표 상 유효한 (도메인, 지표) 쌍만** 랜덤으로 뽑는다.
- 도메인 15 × 평균 유효지표 ≈ **60~80장짜리 카드풀**이 짧은 리스트 두 개에서 나옴. 도메인 하나 추가 시 여러 카드가 동시 증가(확장성).

### 라운드 진행

1. **촉냥 지정**(로테이션) → 카드 1장 오픈 + 정답 지점(촉냥만).
2. 촉냥 **단서 제출**(제한시간 내).
3. 나머지 각자 **다이얼 조정 → 동시 확정**.
4. **채점:** 각 추측의 오차로 점수 부여 → 누적.
5. 다음 촉냥으로 로테이션.

### 단서 규칙 (반칙 방지 · 자율 + 명시 금칙)

- 숫자/퍼센트 직접 언급 금지("70%야" 무효).
- 스펙트럼 양끝 단어 그대로 말하기 금지.
- 지표형에서 정답 인스턴스를 그대로 노출하는 메타 발언 금지.
- (시스템이 의미 검증은 못 하므로 코드네임처럼 **자율 준수 + 신고** 방식. 위반 신고 시 해당 라운드 무효/재출제.)

### 점수 밴드 (오차 허용 = 방 옵션)

| 오차 | 보통(기본) | 빡빡 | 널널 |
| --- | --- | --- | --- |
| 정중앙 4점 | ≤5% | ≤2.5% | ≤7.5% |
| 근접 3점 | ≤10% | ≤5% | ≤15% |
| 애매 2점 | ≤15% | ≤7.5% | ≤22.5% |
| 빗나감 0점 | 그 외 | 그 외 | 그 외 |

### 승리조건 (방 옵션)

- **목표점수제:** 먼저 누적 N점(기본 15) 도달 → 승. (개인전, 인원 많을 때)
- **고정 라운드제:** R라운드 후 최고점 승.
- **세트제(몇판몇승):** 3세트, 세트당 목표 8점, 2세트 선취 = 매치 승.
- **협력 모드:** 팀 합산으로 R라운드 안에 누적 X점 = 클리어/실패. (대전 승패 없음)

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **스펙트럼 해상도** → 0~100(연속). 다이얼은 1% 단위.
2. **점수 밴드** → 위 표. 기본 "보통", 방에서 빡빡/널널 선택.
3. **카드 비율** → 개념형 : 지표형 = **4 : 6**(지표형이 구체적이라 뻔함 덜함). 방에서 "개념형만/지표형만/혼합" 선택 가능.
4. **단서 제한시간** → 촉냥 **30초**, 추측 **20초**.
5. **라운드 수** → 전원 1회 촉냥(인원 ×1)이 1사이클. 기본 2사이클.
6. **목표 점수** → 개인전 15점 / 세트당 8점(2세트 선취).
7. **인원** → 2~8(권장 4~6). 촉냥 1 + 추측 2 이상일 때 경쟁이 재밌음. 2인은 협력 모드(촉냥·추측 교대로 팀 점수).
8. **동점 처리** → 최고점 동점 시 서든데스 1라운드(가장 가깝게 맞춘 사람 승).

> 2·4·6은 실측 핵심 — "평균 몇 %나 빗나가는지 / 한 라운드가 몇 초 걸리는지" 재서 밴드 폭·제한시간·목표점수를 맞춘다.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                        |
| --- | --------------- | ------------------------------------------------ |
| 1   | **로비 / 매칭** | 2~8인 매칭, 방 생성, 오차·승리조건·카드종류 설정  |
| 2   | **대기 / 준비** | 규칙·인원·모드 표시, 준비 완료                    |
| 3   | **촉냥 화면**   | 스펙트럼 + **정답 지점 표시** + 단서 입력         |
| 4   | **추측 화면**   | 스펙트럼 + 단서 표시 + 다이얼 + 확정              |
| 5   | **공개/채점**   | 정답 지점 공개 + 각자 추측 위치 + 점수 애니       |
| 6   | **결과**        | 순위·누적점수, (세트제면) 세트 스코어, 재시작     |
| 7   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                      |

### 게임 메인 구성 요소

- **스펙트럼 바** — 양극 라벨(개념형) 또는 주제·지표 라벨(지표형), 정답 존(촉냥만).
- **다이얼** — 추측자용, 드래그로 % 조정 후 확정.
- **단서 표시** — 촉냥이 낸 단서 텍스트.
- **점수 트래커** — 각자 누적 점수, 현재 촉냥 표시.
- **채점 오버레이** — 정답 지점 + 각 추측 마커 + 획득 점수.

### 서버/로직이 처리할 것

- **카드 뱅크** — 개념형 리스트 + (도메인, 지표) 궁합표. 유효 조합만 랜덤 추출.
- **정답 지점 생성** — 라운드마다 0~100% 랜덤(시드 기반, 촉냥에게만 전달).
- **채점기** — |추측 − 정답| → 오차 밴드로 점수 산출(단순 뺄셈·구간 비교, AI 불필요).
- **라운드/승리 관리** — 촉냥 로테이션, 누적 점수, 승리조건 판정.

### 통신

- **라운드당: 단서 텍스트 1건(촉냥→전원) + 추측 % 1개(각자→호스트) + 정답·점수 브로드캐스트 1건.** → 초경량. 정답 지점은 촉냥에게만, 나머지는 채점 시점에 공개(치트 방지 위해 호스트/서버 보관).

## 라인업에서의 위치

- 1번 모순(연역) · 2번 냥호(귀납) · 3번 우다다(순발력) · 4번 냥탈출(협동)
- **신규 냥파장** = **감각 캘리브레이션·소통** (2~8인) ← 정답이 없는 주관 지표를 두고 "남의 감각을 읽는" 축. 논리·반응·기억·속임과 다른 뇌. **인원 확장성이 커서(최대 8인) 파티성 강함.**
- 공통: 가벼운 통신(단서 1줄 + 추측 1개), 스펙트럼·다이얼 UI라 Canvas 불필요, **AI 없이 사람이 콘텐츠 생성 + 작은 카드 뱅크**로 성립.
