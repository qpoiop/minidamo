# 틱택토 — 기획 정리서

> 2인 클래식 3-in-a-row. 3×3 격자에 O/X 를 번갈아 두어 한 줄을 먼저 완성하면 라운드 승, 매치 옵션(3판 2선승 등)에 지정된 선승 수 먼저 달성한 쪽 매치 승.
>
> **구현 상태:** v1.1.0 라이브 (`src/features/games/tictactoe/`). thumbKind/코드는 `tictactoe`. 게임 등록 첫 슬롯 · 온보딩용 앵커.

---

## 컨셉 · 역할

- **역할:** 호스트 = O, 게스트 = X. 첫 라운드 선공은 호스트, 이후 라운드는 직전 패자 선공 (무승부 시 순서 유지).
- **성격:** 완전정보 · 결정론 · 짧은 매치. 룰 학습 부담이 없으므로 P2P 연결·매치 흐름·핸드오버 검증용 첫 게임으로 배치.

## 진행

1. 로비에서 라운드 수 옵션 선택 (3판 2선승 / 5판 3선승 / 7판 4선승).
2. 게임 시작 → 3×3 그리드 렌더. 내 턴에만 셀 인터랙션 가능 (반대 턴 시 회색 오버레이 + 턴 문구).
3. 셀 탭 → 마크 확정 → P2P 로 상대에게 브로드캐스트 → 승/무 판정 → 다음 라운드 or 매치 종료.

## 승패

- **라운드 승:** 가로·세로·대각선 3연속. 승리 라인은 pulse 효과로 강조.
- **매치 승:** 매치 옵션 선승 수 먼저 달성.
- **무승부:** 9칸 모두 채워 라인 없음 → 다음 라운드로 (선공 유지).

## 인게임 UI

- 상단 헤더: 코드 라벨(TICTACTOE) · 호스트 재시작 칩 · 나가기 칩 · 도움말/채팅.
- 중앙 그리드: `.ttt-cell` — 라인 승리 시 라임 하이라이트, 무승부 시 무광 그레이.
- 하단 HUD: 참가자 스코어 · 실시간 온라인 배지 · 상대 이름/닉네임.

## 옵션 · 확장 여지

- 현재 옵션: 라운드 수 3/5/7. 향후 「먼저 X판」 대신 「승률 60% 이상」 같은 통계 종결도 검토.
- 확장 (미구현): 3×3 → 4×4 misère, 3D 큐브(트리플-3), 시간제한 카운트다운.
