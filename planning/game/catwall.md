# 냥길막 (가칭) — 기획 정리서

> 2인 완전정보 추상 전략. 격자 위에서 내 고양이를 **반대편 끝줄까지** 먼저 데려가면 승리. 매 턴 한 칸 이동하거나, **벽(방석)을 세워** 상대의 길을 미로처럼 막을 수 있다. 벽은 개수가 정해져 있어 언제 달리고 언제 막을지가 승부. 운도 숨김도 없는, 순수 **수읽기** 게임. (쿼리도 기반)

_가칭 후보: 냥길막 / 방석 미로 / 냥달리기_
_(라인업에서 빠진 '완전정보 추상 전략' 축. 추리(숨은 정보)·순발력(반응)과 달리, 모든 게 보이는 판에서 오직 계산으로 이긴다)_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 내 고양이를 **반대편 끝줄**에 먼저 도착시켜라. 벽을 세워 상대를 돌아가게 만들 수 있다.

### 화면

- 격자 보드 **전체가 보임**(숨김 없음). 내 고양이·상대 고양이·세워진 벽이 다 보인다.
- 각자 **남은 벽 개수**가 표시된다.

### 내 턴에 하는 것 (둘 중 하나)

1. **이동** — 내 고양이를 상하좌우 **한 칸**. (벽이 막고 있으면 그쪽으론 못 감)
2. **벽 세우기** — 칸 사이 홈에 **2칸짜리 벽**을 놓아 통로를 막는다. 남은 벽에서 하나 소모.

### 벽 규칙

- 벽끼리 **겹치거나 교차 금지.**
- **상대(또는 나)의 길을 완전히 막는 벽은 금지** — 항상 도착까지 가는 길이 최소 하나는 남아야 한다(시스템이 자동 검증).

### 마주쳤을 때 (건너뛰기)

- 상대 고양이가 바로 앞 칸에 있으면 **뛰어넘어** 그 뒤 칸으로 갈 수 있다.
- 뒤가 벽/보드 끝이면 대신 **대각선**으로 비켜 갈 수 있다.

### 승리

- 내 고양이가 **반대편 끝줄의 아무 칸**에나 도착하면 즉시 승리.

### 핵심 감각

- 벽은 유한하다 → 아껴 뒀다 결정적일 때 막고, 남발하면 정작 필요할 때 못 막는다.
- 상대를 막는 건 곧 **내 거리도 계산**하는 일 — 상대가 +3칸 돌아가게 만들되 내가 더 손해면 헛수.
- 벽으로 만든 미로가 **나중엔 나를 가둘 수도** 있다. 판 전체를 몇 수 앞서 읽어야 한다.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2인 전용.**
- 보드: **9×9 칸**(기본), 빠른 판은 **7×7** 옵션.
- 시작 위치: 각자 자기 쪽 **끝줄 중앙 칸.** 목표는 **반대편 끝줄**(그 줄의 어느 칸이든).
- 각자 **벽 재고**를 가지고 시작(개수는 C 참고).
- 선공은 시드로 랜덤 결정.

### 턴 진행 (순번 교대)

1. 자기 차례에 **행동 택1:**
   - **(a) 이동** — 인접 칸(상하좌우)으로 1칸. 두 칸 사이에 벽이 없어야 함.
   - **(b) 벽 세우기** — 칸 경계 홈에 2칸 길이 벽(가로/세로)을 놓음. 재고 −1.
2. **이동 세부(건너뛰기):**
   - 목표 칸에 상대 고양이가 있으면, 그 **직선 뒤 칸**으로 건너뜀(그 사이·뒤에 벽 없을 때).
   - 뒤가 벽/보드 끝이면 상대의 **양옆 대각선 칸** 중 하나로 이동(그쪽이 안 막혔을 때).
3. **벽 유효성(시스템 자동 검증):**
   - 다른 벽과 **겹침·교차 불가.**
   - 놓은 뒤에도 **두 고양이 모두 목표 끝줄까지 도달 경로가 존재**해야 함(완전 봉쇄 금지). 위반 배치는 거부.
4. 다음 사람 차례. 먼저 반대편 끝줄에 닿는 사람이 **즉시 승리.**

### 왜 머리를 쓰는가 (설계 의도)

- **거리 계산:** 매 수 "내 최단 경로 vs 상대 최단 경로"를 비교. 벽 한 장이 만드는 우회 칸 수를 저울질.
- **자원 배분:** 벽은 유한(기본 10). 초반 남발 → 종반 무방비. 언제 쓸지가 실력.
- **완전정보 수읽기:** 숨김·운 없음. 상대의 다음 몇 수를 읽어 길목을 선점하거나, 상대가 세울 벽을 예측해 미리 우회. 순수 계산이 승부를 가른다.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **보드 크기** → 기본 **9×9**, 빠른 판 **7×7** 옵션. 큰 판일수록 벽의 전략 폭↑, 판 길이↑.
2. **벽 개수** → 9×9는 **각 10개**, 7×7은 **각 7개**. (쿼리도 표준 기준, 너무 많으면 교착·늘어짐)
3. **턴 제한시간** → **턴당 30초.** 수읽기 시간은 주되 늘어짐 방지. 초과 시 자동 최단경로 1칸 전진.
4. **선공 보정** → 선공이 약간 유리 → 실측 후 필요하면 **후공 벽 +1** 또는 후공 반 칸 앞 배치로 보정.
5. **매치** → **3판 2선승**, 판마다 **선공 교대**(공정성).
6. **동점/무승부** → 구조상 무승부 없음(먼저 도착이 명확). 시간패는 없음(자동 전진).

> 1·2·4는 실측 핵심 — "평균 몇 수에 판이 끝나는지 / 선공 승률이 얼마나 치우치는지" 재서 보드 크기·벽 수·선공 보정을 맞춘다.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                             |
| --- | --------------- | ---------------------------------------------------- |
| 1   | **로비 / 매칭** | 2인 매칭, 방 생성, 보드 크기(9×9/7×7)·벽 수 설정      |
| 2   | **대기 / 준비** | 시드·규칙 표시, 준비 완료                             |
| 3   | **게임 메인**   | 전체 격자 + 두 고양이 + 벽 + 남은 벽 수 + 턴 타이머   |
| 4   | **행동 연출**   | 이동/벽 세우기 애니, 건너뛰기 강조                    |
| 5   | **결과**        | 승패, 최종 보드(경로·벽 배치), 판수 스코어, 재시작    |
| 6   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                          |

### 게임 메인(3번) 구성 요소

- **전체 격자 보드** — 칸·칸 경계 홈(벽 놓을 자리)·두 고양이 위치·세워진 벽 표시.
- **행동 컨트롤** — [이동] 방향 선택 / [벽] 놓을 위치·방향(가로/세로) 선택 후 확정.
- **남은 벽 표시** — 각자 벽 재고.
- **경로 힌트(선택·초보)** — 내 현재 최단 경로 하이라이트 on/off.
- **턴 타이머** — 30초 카운트다운.

### 서버/로직이 처리할 것

- **보드 상태기** — 칸·벽·두 고양이 위치 관리(완전 공개 상태, 숨김 없음).
- **이동 검증** — 인접·벽 차단·건너뛰기(직선/대각) 규칙 판정.
- **벽 검증(핵심)** — 겹침/교차 체크 + **양쪽 경로 존재 BFS**(완전 봉쇄 금지). 격자 BFS 수준, 가벼움.
- **승리·매치 관리** — 끝줄 도달 판정, 판수·선공 교대.

> **AI 불필요 근거:** 완전정보 추상 전략이라 콘텐츠 뱅크가 **아예 없다.** 시스템은 규칙 판정(이동·벽·경로 BFS)과 승패만 계산. LLM·콘텐츠 생성 전혀 불필요, 구현 난이도도 낮음(격자 + BFS).

### 통신

- **턴마다 각자 행동 1건**(이동 방향 or 벽 위치+방향) 전송 → 상대에게 브로드캐스트 1건. → 턴당 초경량 메시지. 실시간 물리·프레임 동기화 불필요(순번제).

- 공통: 가벼운 통신(행동 1건/턴), 격자 + BFS 판정이라 실시간 물리 불필요, HTML/CSS(격자 렌더)로 구현. **콘텐츠 뱅크 0 · AI 불필요**로 구현 난이도 최저 수준.
