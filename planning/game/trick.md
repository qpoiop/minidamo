# 모루먼쇼 — 기획 정리서

> 2인 트릭테이킹 대전. 카드를 한 장씩 내 겨루고, 이긴 사람이 그 트릭의 두 장을 가져가 **점수를 쌓는다.** 으뜸패(트럼프)와 점수 카드의 흐름을 읽어, 언제 큰 패를 내고 언제 버릴지 고른다. 손패가 3장뿐이라 **가벼운데** 덱이 도는 순서와 상대 손을 추적하는 **기억·계산**이 승부. (브리스콜라 기반)

_이름: 모루먼쇼 (트루먼쇼 말장난 + 모)_
_(라인업에서 빠진 '카드 관리·트릭테이킹' 축. 추리와 달리 정보를 논리로 캐는 게 아니라, 도는 카드와 상대 손을 추적하며 '점수 흐름을 관리'하는 뇌)_

> **구현 상태:** v1.0.0 라이브 (`src/features/games/trumeon/`, `briscola.ts` · `Trumeon.tsx`). thumbKind/코드는 `trick`. 2인 · 손패 3 · 트럼프 무늬 자동 지정 · 트릭 판정 (트럼프 우선 + 강도 서열). matchOption 으로 승점 기준(41/61/81). 종반 무늬 강제 규칙 반영. 기억 보조(캐주얼 카운터) 는 다음 사이클.

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 카드로 겨뤄 이긴 트릭의 점수를 모아라. **먼저 61점**을 넘기면 승리.

### 화면

- 내 **손패 3장**(나만 봄), 가운데 **으뜸패(트럼프) 무늬** 표시, 옆에 **더미(남은 카드) 수**.
- 트릭 자리(양쪽이 낸 카드), 각자 **획득 점수 게이지.**

### 카드와 점수

- 4가지 냥 무늬(치즈·검정·삼색·벵갈) × 값. **점수 카드:** A=11, 10=10, K=4, Q=3, J=2, 나머지(9·8·7…)=0. (총 120점)
- **으뜸패(트럼프):** 매 판 하나의 무늬가 으뜸. 으뜸은 다른 무늬 전부를 이긴다.

### 한 트릭 흐름

1. **선(리드)**이 카드 1장 냄 → **후(팔로)**가 1장 냄.
2. **승자 판정:** 같은 무늬면 높은 값 승, 후가 으뜸을 내면 승(선이 으뜸이 아닐 때). 무늬 안 맞고 으뜸도 아니면 선 승.
3. 승자가 **두 장 획득(점수 적립)** → 각자 더미에서 1장씩 보충 → 승자가 다음 선.
4. 더미가 마르면 손패 3장으로 마무리(그때부턴 **무늬 따르기 강제**).

### 승리

- 획득 점수 **61점 선도달** = 승. (한 판 120점이라 61이면 과반)

### 핵심 감각

- 점수 카드(A·10)를 언제 먹고 언제 안 뺏길지 — 으뜸을 아껴 결정적일 때 쓴다.
- 상대가 낸 카드로 **상대 손·남은 으뜸을 추적** → 기억이 곧 우위.
- 0점 잡패로 흘려보내고 큰 트릭만 챙기는 완급 조절.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2인 전용.**
- 덱: **40장**(4무늬 × A,2,3,4,5,6,7,J,Q,K → 값 카드 10종). 점수는 위 표(A11·1010·K4·Q3·J2·나머지0, 합 120).
- 각자 **손패 3장** 배분. 남은 34장은 **더미(스톡)**. 더미 맨 위 카드를 옆으로 눕혀 **으뜸 무늬** 지정(그 카드는 더미 맨 마지막에 뽑힘).
- 시드로 셔플·선공 결정. 손패는 각자만 봄(서버 보관·치트 방지).

### 트릭 진행 (더미 있는 동안)

1. **선이 1장, 후가 1장** 낸다. **이 단계엔 무늬 따르기 없음**(아무 카드나 가능 — 브리스콜라 특성).
2. **승패 판정(우선순위):**
   - 둘 다 으뜸 → 높은 값 승.
   - 한쪽만 으뜸 → 으뜸 승.
   - 으뜸 없음 & 같은 무늬 → 높은 값 승.
   - 으뜸 없음 & 다른 무늬 → **선(먼저 낸 쪽) 승**(후가 무늬를 못/안 맞춤).
3. 승자가 두 장 가져가 **점수 적립**(카드 점수 합).
4. **보충:** 승자 먼저 더미에서 1장, 다음 패자 1장. (으뜸 지정 카드는 마지막에 뽑힘)
5. 승자가 다음 트릭 선.

### 종반 (더미 소진 후)

- 더미가 마르면 손패 3장으로 6트릭 마무리.
- 이때부터 **무늬 따르기 강제:** 후는 선의 무늬가 있으면 반드시 따라야 하고, 없으면 으뜸 우선, 그도 없으면 아무 카드. (종반 계산 게임으로 전환)

### 종료 & 승패

- 한쪽이 **61점 도달 즉시 승**(원하면 판 끝까지 진행 후 합산 옵션).
- 60-60 균등은 40장·120점 구조상 드묾 → 발생 시 **무승부 재경기** 또는 옵션 "마지막 트릭 획득자 승".

### 왜 머리를 쓰는가 (설계 의도)

- **점수 흐름 관리:** 큰 점수 카드를 지키고 뺏는 타이밍. 0점 카드로 손실 최소화.
- **카드 추적·기억:** 나온 으뜸·A·10을 세어 상대 손을 좁힘 → 남은 위험 파악.
- **완급:** 초반 더미 국면(무늬 자유)은 유연, 종반(무늬 강제)은 정밀 계산. 두 국면의 전환 관리가 실력.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **덱·점수** → 브리스콜라 표준 40장·120점(A11·1010·K4·Q3·J2). 검증된 밸런스.
2. **손패** → **3장**(가볍고 회전 빠름). 방 옵션 없음(표준 유지 권장).
3. **승점 기준** → **61점 선도달**. 옵션 "판 종료 후 합산".
4. **턴 제한시간** → **트릭당 각 15초.** 초과 시 자동 최소손실 카드(가장 낮은 0점 잡패) 자동 제출.
5. **매치** → **3판 2선승**, 판마다 선공 교대·새 시드.
6. **기억 보조(선택)** → '나온 으뜸/점수 카드 카운터' on/off(기본 off, 캐주얼 on).

> 4·6은 실측 핵심 — "한 트릭 평균 소요 / 기억 부담이 과한지" 재서 제한시간·보조 정책을 조정.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                              |
| --- | --------------- | ----------------------------------------------------- |
| 1   | **로비 / 매칭** | 2인 매칭, 방 생성, 승점기준·보조 설정                  |
| 2   | **대기 / 준비** | 시드·규칙 표시, 준비 완료                              |
| 3   | **게임 메인**   | 손패 3장 + 으뜸 무늬 + 더미 수 + 트릭 자리 + 점수 게이지|
| 4   | **트릭 연출**   | 두 카드 대결 → 승자 강조 → 획득 애니                   |
| 5   | **국면 전환 연출** | 더미 소진 → "이제 무늬 따르기!" 배너                 |
| 6   | **결과**        | 최종 점수, 판수 스코어, 재시작                         |
| 7   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                           |

### 게임 메인(3번) 구성 요소

- **손패 3장** — 나만 보임, 각 카드에 **무늬·값·점수 pip** 표시. 탭+확정으로 제출.
- **으뜸 무늬 표시** — 상단에 트럼프 아이콘 상시.
- **더미 카운터** — 남은 장수 + 마지막 으뜸카드 눕힌 표시.
- **트릭 자리** — 선/후 카드, 승자 하이라이트.
- **점수 게이지** — 각자 획득 점수 / 61 진행 바.

### 인게임 안내·경고·피드백 장치 (모바일 화면 기준)

- **점수 값 상시 표기:** 각 카드에 작은 점수 배지(A=11 등) → 초보도 큰 카드를 즉시 인지.
- **낼 수 있는 카드 안내:** 종반(무늬 강제) 국면에서 **낼 수 없는 카드는 흐리게 잠금** + 낼 수 있는 카드만 강조. 잘못 탭 시 "이 국면엔 무늬를 따라야 해요" 토스트.
- **국면 전환 경고등:** 더미가 **2장 남으면 노란 경고** ("곧 무늬 따르기 국면"), 소진 순간 전체 배너 + 규칙 요약 → 규칙이 바뀌는 걸 놓치지 않게.
- **제출 2단계 확정:** 탭=미리보기(카드 살짝 올라옴), [내기]=확정. 오제출 방지, 특히 큰 점수 카드는 "A(11점)를 냅니다" 재확인 옵션.
- **승패 사유 표기:** 트릭 판정 시 "으뜸으로 이김 / 같은 무늬 높은 값" 등 이유 라벨 → 규칙 학습.
- **타이머·자동제출 고지:** 15초 링, 초과 시 "가장 낮은 잡패 자동 제출됨" 토스트로 무슨 일이 있었는지 안내.
- **기억 보조 토글:** 캐주얼 모드에서 '나온 A·10·으뜸' 카운터 패널 노출. 랭크전에선 잠금(순수 기억).
- **네트워크:** 상대 지연 스피너, 끊김 시 재접속 대기(손패·더미는 서버 시드 상태로 복원).

### 서버/로직이 처리할 것

- **덱·배분기** — 시드 셔플, 손패 3장 + 더미, 으뜸 지정. **손패는 소유자에게만.**
- **트릭 판정** — 우선순위(으뜸/무늬/값) 비교, 획득·점수 적립.
- **보충·국면 관리** — 더미 드로우 순서, 소진 시 무늬 강제 전환, 유효 제출 검증.
- **승점·매치 관리** — 61 도달 판정, 판수·선공 교대.

> **AI 불필요 근거:** 콘텐츠는 **고정 40장 덱**. 시스템은 셔플·트릭 판정·점수 집계만. 상대 손 추적·완급은 사람 몫. LLM 불필요.

### 통신

- **트릭마다 각자 제출 카드 1건**(카드 id) → 판정·보충 결과 브로드캐스트 1건. → 트릭당 소량. 손패·더미 실제값은 서버 보관(치트 방지), 공개는 제출·판정 시점만.
