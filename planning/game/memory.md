# 메모리 매치 — 기획 정리서

> 2인 기억력 대결. 뒷면으로 깔린 카드 8~15쌍 중 매 턴 2장을 뒤집어 짝을 맞춘다. 성공 시 카드 획득 + 턴 유지, 실패 시 다시 엎어짐 + 턴 넘김. 전체 쌍이 다 열리면 획득 수 우위 쪽 매치 승.
>
> **구현 상태:** v1.0.0 라이브 (`src/features/games/memory/`). thumbKind/코드는 `memory`. 2축 옵션 (카드 쌍 수 × 배치 시드) 지원.

---

## 컨셉 · 역할

- **역할:** 호스트가 카드 배치 시드 발행 → 양쪽 동일 배치 재현. 턴 판정도 호스트 권위.
- **성격:** 턴제 · 결정론. 상대가 뒤집는 카드 위치도 정보가 되므로 관찰이 실력의 절반. 순수 기억력 축.

## 진행

1. 로비에서 옵션 선택 (카드 쌍 수 · 시드/배치 프리셋).
2. 호스트가 셔플 seed 발행 → 게스트 동기화.
3. 매 턴 카드 2장 순서대로 오픈:
   - **동일 심볼:** 획득 · 턴 유지 · 스코어 +1.
   - **다른 심볼:** 카드 다시 뒤집힘 · 턴 넘김.
4. 모든 쌍이 열리면 매치 종료.

## 승패

- **매치 승:** 획득 쌍 수 우위 쪽. 동수면 무승부.

## 인게임 UI

- 상단 스코어: 내 획득 쌍 / 상대 획득 쌍 · 남은 쌍.
- 중앙 그리드: 카드 쌍 수에 따라 4×4 / 4×5 / 5×6 등. 카드 뒤집기 애니메이션 250ms.
- 하단 HUD: 참가자 스코어 · 상대 턴 표시.

## 옵션 · 확장 여지

- 현재 옵션: 카드 쌍 수 (8·10·12·15) × 배치 시드.
- 확장 (미구현): 시간제한, 방해 카드(트랩), 3매치 릴레이 카드.

## 동기화 세부

- 카드 오픈: 매 클릭마다 CARD_FLIP { idx } 브로드캐스트. 짝 판정은 양쪽에서 로컬 계산 (같은 seed 라 결과 일치).
- 턴 넘김: 실패 시 setTimeout 900ms 이후 자동 flip-back + 턴 스위치.
