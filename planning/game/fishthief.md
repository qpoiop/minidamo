# 생선 도둑 (가칭) — 기획 정리서

> 2~4인 블러핑 대전. 훔친 장물 카드를 "이건 ○○야"라고 우기며 옆 사람에게 떠넘긴다. 믿을지 의심할지, 그리고 나는 진실을 말할지 뻥을 칠지. 같은 종류 4장을 먼저 떠안는 사람이 진다.

_가칭 후보: 생선 도둑 / 장물 떠넘기기 / 냥손버릇_
_(라인업 유일의 심리·블러핑 대전. 추리 2종(연역·귀납)이 '정보를 모으는' 게임이라면, 이건 '정보를 흘리고 속이는' 게임)_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 장물을 "이건 ○○야"라고 우기며 떠넘겨라. 같은 장물 **4장**을 떠안으면 패배.

### 장물은 5종류

🐟 생선 · 🐭 생쥐 · 🐦 참새 · 🧦 양말 · 🔔 방울
(각 종류 여러 장. 전부 "누군가 훔쳐온 물건"이라는 설정)

### 내 차례에 하는 것

1. 내 손패에서 카드 1장을 **뒤집은 채** 옆 사람에게 밀며 선언한다.
   - 예: "이건 🐟 **생선**이야." (**진실이든 뻥이든 자유**)
2. 받은 사람이 판단한다 → **맞다 / 아니다 / 몰래 보고 넘기기** 중 하나.

### 카드를 받은 사람의 3택

| 선택 | 하는 일 | 결과 |
| :-- | :-- | :-- |
| **"맞다"** | 선언이 진실이라고 주장 | 뒤집어 확인 → **틀린 사람이 카드를 앞면으로 가져감** |
| **"아니다"** | 선언이 뻥이라고 주장 | 뒤집어 확인 → **틀린 사람이 카드를 앞면으로 가져감** |
| **몰래 보기 → 넘기기** | 카드를 나만 슬쩍 확인 후, **다른 사람**에게 새 선언과 함께 다시 떠넘김 | 폭탄 돌리기. 단 이미 이 카드를 만진 사람에겐 못 넘김 |

### 패배 조건

- 자기 앞에 **같은 종류 장물이 4장** 쌓이면 그 사람 **즉시 패배(탈락).**
- 카드를 받아야 하는데 **넘길 사람이 없다**(전원 이미 그 카드를 봄)면 받은 사람이 그냥 가져감.

### 승리

- **마지막까지 안 터진 사람**이 승리. (2인은 1:1 심리, 3~4인은 표적·눈치 삼파전)

### 핵심 감각

- 진실을 섞어 상대의 "의심 습관"을 역이용한다.
- 남의 앞에 뭐가 쌓였는지 보고 **약점 종류를 노려** 떠넘긴다.
- "몰래 보기 → 넘기기"로 폭탄을 다른 사람에게 미룰 수 있다.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2~4인.**
- 장물 카드: 5종류 × 각 여러 장. **인원별 덱 구성 확정값은 C 참고.**
- 시작 시 덱을 시드 기반으로 셔플 → 전원에게 **균등 분배**(자기 손패는 자기만 봄).
- 각 플레이어 앞에는 **공개 장물 구역**(앞면으로 떠안은 카드가 쌓이는 곳). 종류별 개수가 전원에게 보임.

### 한 번의 "떠넘기기" 흐름

1. **출제자**: 손패 1장을 뒤집은 채 **대상 1명**에게 밀고 종류를 선언(진실/뻥 자유).
2. **받은 사람**의 3택:
   - **맞다** — "선언이 진실" 주장. 즉시 공개 판정.
   - **아니다** — "선언이 뻥" 주장. 즉시 공개 판정.
   - **몰래 보기 → 넘기기** — 카드를 자기만 확인. 그 뒤 **아직 이 카드를 안 만진 사람** 중 1명에게 새 선언으로 재출제. (본인은 판단을 미룬 것)
3. **공개 판정**(맞다/아니다 선택 시):
   - 실제 카드 종류 vs 마지막 선언 비교.
   - **판단이 맞으면** → **출제자**가 그 카드를 앞면으로 자기 구역에 가져감.
   - **판단이 틀리면** → **받은 사람**이 그 카드를 앞면으로 자기 구역에 가져감.
   - 즉, 뻥을 간파하거나 진실을 믿어 맞히면 상대에게 카드를 되돌린다.
4. 카드를 앞면으로 가져간 사람이 **다음 라운드 출제자**가 된다.

### 폭탄 돌리기(몰래 보기) 규칙

- "몰래 보기 → 넘기기"를 택하면 카드는 계속 돌 수 있다.
- **이미 그 카드를 만진 사람(출제·경유)에게는 다시 넘길 수 없다.**
- 넘길 대상이 한 명도 안 남으면(전원 경유) → **마지막에 든 사람이 공개 없이 그냥 가져간다.**
- 이 규칙 덕에 폭탄이 무한히 돌지 않고 언젠가 누군가 떠안는다.

### 탈락 & 종료

- 자기 공개 구역에 **한 종류가 4장** 되는 순간 그 사람 **탈락.**
- 탈락자의 남은 손패는 게임에서 제거(덱 소진 가속).
- **최후 1인 생존 = 승리.** (전원 탈락 상황은 규칙상 발생하지 않음 — 한 명이 4장 될 때 나머지는 아직 살아있음)

### 정보 공개 범위

- **공개:** 각자 앞의 장물 종류별 개수(누가 어떤 종류에 몰렸는지 전원이 봄).
- **비공개:** 손패 내용, 현재 도는 카드의 실제 종류, "몰래 보기"로 본 내용.
- **선언 로그:** 이번 카드가 돌며 나온 선언들(누가 뭐라 우겼는지)은 그 카드 판정 전까지 표시. 심리전 근거.

### 왜 머리를 쓰는가 (설계 의도)

- **표적 관리:** 4장에 가까운 종류를 남이 노린다 → 자기 약점을 숨기고 남의 약점을 친다.
- **진실/뻥 믹스:** 항상 뻥이면 읽힌다. 진실을 섞어 상대의 "의심 성향"을 무너뜨린다.
- **넘기기 판단:** 확률이 애매하면 몰래 보고 떠넘겨 리스크를 이연. 단 넘길 곳이 줄면 결국 자기 차례.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **장물 종류 수** → **5종**(생선·생쥐·참새·양말·방울). 추리 게임의 기호 세트와 톤 통일.
2. **패배 임계치** → **같은 종류 4장.** (바퀴벌레포커 표준. 3장은 너무 빨리 끝, 5장은 늘어짐)
3. **덱 구성(인원별)**
   - **2인:** 각 종류 6장 = 30장. 손패 15장씩. (덱이 커야 4장 몰기까지 심리전이 이어짐)
   - **3인:** 각 종류 6장 = 30장. 손패 10장씩.
   - **4인:** 각 종류 8장 = 40장. 손패 10장씩.
4. **선공** → 시드로 랜덤 결정. 이후엔 "카드를 떠안은 사람"이 출제권 승계.
5. **소프트 타이머(선택)** → 판단 1회당 **20초** 소프트 리밋. 초과 시 자동 "몰래 보기 → 넘기기" 또는 랜덤 판단(늘어짐 방지).
6. **매치** → **단판제.** (한 판이 길고 탈락 구조라 3판2선승은 과함. 대신 판마다 새 시드)
   - 선택: 라운드 리그로 여러 판 누적 승점제도 가능(추후).
7. **동점/무승부** → 최후 1인 생존이 명확해 무승부 거의 없음. 4인에서 동시에 두 명이 4장 되는 케이스는 규칙상 순차 처리(카드 이동은 1장씩)라 불가.

> 2·3은 밸런스 핵심 — "평균 몇 번 떠넘겨야 누가 터지는지" 실측해 덱 크기와 임계치를 맞춘다. 판이 너무 빨리 끝나면 덱을 키우거나 손패를 늘린다.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                                   |
| --- | --------------- | ---------------------------------------------------------- |
| 1   | **로비 / 매칭** | 2~4인 매칭, 방 생성, 인원 표시                              |
| 2   | **대기 / 준비** | 시드·인원·규칙 표시, 준비 완료                             |
| 3   | **게임 메인**   | 내 손패 + 상대별 공개 구역 + 도는 카드 + 선언/판단 액션     |
| 4   | **떠넘기기 연출** | 카드 밀기 애니 + 선언 말풍선("이건 🐟야")                  |
| 5   | **공개 판정 연출** | 카드 오픈 → 진실/뻥 판정 → 누가 가져가는지 표시           |
| 6   | **탈락 연출**   | 4장 완성 순간 강조 연출                                     |
| 7   | **결과**        | 최후 생존자 승리, 각자 떠안은 장물 요약, 재시작            |
| 8   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                                |

### 게임 메인(3번) 구성 요소

- **내 손패** — 나만 보이는 카드 목록(종류 표시). 출제 시 1장 선택.
- **상대별 공개 구역** — 각 플레이어 앞의 장물 종류·개수(4장 임박 시 경고 색).
- **도는 카드 트레이** — 현재 떠넘겨지는 카드(뒷면) + 지금까지의 선언 로그.
- **대상 선택 UI** — 출제/넘기기 시 넘길 상대 선택(이미 만진 사람은 비활성).
- **액션 버튼** — [선언하고 넘기기] / [맞다] / [아니다] / [몰래 보고 넘기기].
- **선언 입력** — 5종 아이콘 중 하나 선택해 "이건 ○○" 선언.

### 서버/로직이 처리할 것

- **덱 생성·분배기** — 시드 기반 셔플, 인원별 덱 구성대로 균등 분배.
- **카드 이동 상태기** — 현재 카드의 실제 종류(비공개), 경유자 목록(넘기기 제약), 선언 로그.
- **판정 엔진** — 마지막 선언 vs 실제 종류 → 출제자/수신자 중 획득자 결정.
- **탈락 판정** — 각자 종류별 카운트, 4장 도달 시 탈락·게임 종료.
- **턴/출제권 관리** — 획득자 = 다음 출제자, 넘길 대상 유효성 검증.

### 통신

- **떠넘기기 이벤트 1건**(카드 id + 선언 + 대상), **판단 이벤트 1건**(맞다/아니다/넘기기), **판정 결과 브로드캐스트 1건**. → 턴마다 소량 메시지. 실시간 물리·위치 동기화 없음. 카드 실제 종류는 판정 시점에만 공개(치트 방지 위해 서버/호스트가 보관).

## 라인업에서의 위치

- **1번 코드네임: 모순** = 조건부 단서 **연역** 추리 (대전)
- **2번 냥호 브레이커** = 추측 피드백 **귀납** 추리 (대전)
- **3번 우다다 대시** = 순발력·조작 (대전)
- **4번 냥탈출** = 협동·소통 (협동)
- **신규 생선 도둑** = **블러핑·심리** (2~4인) ← 라인업 유일의 심리 대전. 추리 2종이 '정보를 정직하게 모으는' 게임인 반면, 이건 '정보를 흘리고 속이는' 정반대 뇌를 씀.
- 공통: 가벼운 통신(카드 id + 선언 + 판단), 손패·구역 UI라 Canvas 불필요, HTML/CSS로 고퀄 가능.
