# 미니 탁구 — 기획 정리서

> 2인 실시간 초저지연 핑퐁. 화면 좌우 드래그로 패들 조작. 랠리마다 공 속도가 소폭 가속되어 반사 신경 승부로 이어짐. 목표 점수 선착 시 매치 승.
>
> **구현 상태:** v1.2.0 라이브 (`src/features/games/pingpong/`). thumbKind/코드는 `pingpong`. 실시간 물리 시뮬레이션(공 좌표·속도)는 호스트 권위 · 게스트는 BALL_SYNC 수신.

---

## 컨셉 · 역할

- **역할:** 호스트가 물리 authority. 공 좌표·충돌·득점 판정을 호스트가 계산하고 60Hz BALL_SYNC 브로드캐스트. 게스트는 자기 패들 입력(PADDLE_INPUT) 만 호스트에 보냄.
- **성격:** 실시간 액션. 카드/턴제 게임 사이에서 반사 신경 축 확보. 조작이 좌우 드래그로만 이뤄져 학습 부담 최소.

## 진행

1. 로비에서 목표 점수 선택 (3/5/7점).
2. SERVE 카운트다운(3초) → 호스트 랜덤 방향 서브.
3. 공이 상대 골대를 넘기면 득점 → 다음 서브 (패자 서브).
4. 패들 충돌 시 공 속도 +5.5% (최대 7.5 캡). 랠리 카운트 헤더에 표시.

## 승패

- **득점:** 상대 골대(화면 상단/하단) 통과.
- **매치 승:** 목표 점수 먼저 도달.
- **무승부 없음.** 첫 도달자가 매치 승.

## 인게임 UI

- 상단 스코어: 내 점수 / 상대 점수 · 랠리 수 · 서브 카운트다운.
- 중앙 필드: 패들 2개 + 공. 공 궤적은 그리지 않음 (가독성 우선).
- 하단 조작: 패들 드래그 영역. 손을 뗄 필요 없이 이어서 조준 가능.

## 옵션 · 확장 여지

- 현재 옵션: 목표 점수 3/5/7. 랠리 수/시간 기반 종결은 옵션 미노출.
- 확장 (미구현): 파워업 (지연 감소·패들 확장), 각도 스핀, 4인 더블스, 관전 모드.

## 물리 · 동기화 세부

- 서버 tick: 호스트 requestAnimationFrame 루프 · 매 프레임 BALL_SYNC (좌표+속도) 브로드캐스트.
- 게스트는 last-received 상태 보간 (linear). RTT > 100ms 상황에서도 랠리 감각 유지가 목표.
- 충돌 판정: 원-사각형 근접 AABB → 정확 원-라인 세그먼트. 랠리 이어지는 조건 = 패들 상단면 접촉.
