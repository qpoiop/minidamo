# 협동 미로 — 기획 정리서

> 2인 협동. 둘이 깜깜한 미로의 서로 다른 곳에서 시작해, 좁은 시야로 서로를 찾아 만나고, 열쇠를 구해 함께 출구를 밟아 탈출한다. 아무도 미로 전체를 못 본다 → 소통이 강제됨.
>
> **구현 상태:** v1.0.0 라이브 (`src/features/games/escape/`). thumbKind/코드는 `escape`. 이전 초안 명칭 "냥탈출" 은 문서 내부에서만 병기.

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 깜깜한 미로에서 **친구를 찾고, 열쇠를 구해, 같이 탈출!**

### 화면

- 내 고양이는 **화면 중앙 고정.** 카메라가 나를 따라다니고, **주변만 보임**(기본 반경 2칸).
- 지나온 길은 어둡지만 **벽 형태는 기억되어** 보임 → 돌아갈 때 안 헤맴.

### 조작

- **상하좌우 이동.** 아이템·열쇠는 그 칸을 지나가면 자동 획득.

### 탈출 조건

1. **둘이 만나기** — 서로를 찾아 합류
2. **열쇠 구하기** — 맵 어딘가의 열쇠 획득 (아무나 밟으면 팀 공동 획득)
3. **각자 출구 통과** — 조건 충족 시 출구 등장. 두 사람이 **각자 출구 칸을 밟아야** 팀 성공
4. **먼저 나온 쪽은 관전 모드** — 캐릭터 숨김 · 조작 잠금 · 카메라가 남은 친구를 팔로우
5. **30초 남으면 미니맵에 출구 자홍색 별 공개** — 마지막 스퍼트 힌트

### 아이템 (맵에 랜덤 드랍)

| 좋은 것 🟢      | 나쁜 것 🔴                   |
| --------------- | ---------------------------- |
| 시야↑ / 속도↑   | 미로 재구성                  |
| 쉴드 1회 / 열쇠 | 출구 위치 이동 / 몬스터 출현 |

- 좋은 것과 나쁜 것은 **색으로 구분** → 나쁜 건 피할 수 있음.

### 몬스터

- 미로를 랜덤하게 돌아다님. 닿으면 페널티(쉴드 있으면 1회 방어).

### 점수

- **탈출까지 걸린 시간.** 빠를수록 좋음. (모드에 따라 시간제한 유무)

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 격자 미로, **길은 한 블록 폭.** 2인 협동.
- 두 플레이어는 **서로 다른 위치에서 시작.**
- 미로 크기는 **모드/타입으로 선택**(작을수록 빠른 판).

### 시야 & 카메라

- **캐릭터 중앙 고정 + 카메라 팔로우.** 미로 전체가 아니라 내 주변만 렌더.
- **기본 가시 반경 2칸**(내 주변 약 5×5). 그 바깥은 어둠.
- **탐사 안개(fog of war):** 한 번 지나온 칸은 **어둡게 처리되 벽 구조는 계속 보임** → 지나온 길로 되돌아갈 때 길을 앎. (아직 안 가본 곳은 완전 암흑)
- **시야 증가 시 카메라 줌아웃 연동:** 시야 아이템을 먹으면 가시 반경이 늘고, 그에 맞춰 **카메라도 살짝 줌아웃**되어 넓어진 시야가 화면에 자연스럽게 담김.

### 조작 & 상호작용

- 상하좌우 이동. 갈림길 외에는 앞/뒤 두 방향뿐이라 조작 단순.
- 아이템·열쇠 = **해당 칸 통과 시 자동 획득**(별도 버튼 없음).

### 탈출 로직 (핵심)

- **최소 조건 2가지: (1) 두 플레이어 합류, (2) 열쇠 보유.**
- 두 조건이 **모두** 충족되는 순간 → **출구 칸 생성.**
- 출구 생성과 동시에 양쪽 화면에 **출구 방향 안내**(가장자리 화살표 등) 표시.
- 두 플레이어가 **함께 출구 칸에 도달**하면 탈출 성공.
- **진행 상태 UI 상시 표시:** [합류 ✅/⬜] [열쇠 ✅/⬜] 를 화면에 띄워, 지금 뭐가 남았는지 항상 보이게. 두 조건 다 차면 [출구 열림] 으로 전환.

### 아이템 (랜덤 드랍)

- 일정 주기로 맵의 빈 칸에 스폰. **좋은 것/나쁜 것은 색으로 구분**되어 회피 가능.
- **좋은 것:** 시야 증가 / 이동속도 증가 / 쉴드 1회(몬스터 1회 방어) / 열쇠.
- **나쁜 것:** 미로 부분 재구성 / 출구 위치 이동(출구 생성 후라면) / 몬스터 출현.
- 나쁜 효과는 **만회 가능한 선**으로 제한(판이 즉사로 터지지 않게). 협동 게임 특유의 "같이 당황하는" 웃음 포인트로 활용.

### 몬스터 (AI 아님 · 규칙 이동)

- **랜덤 방향 전진.** 벽을 만나면 → 갈 수 있는 방향 중 랜덤 선택. 또는 **2~5초 랜덤 주기**마다 방향 랜덤 변경.
- 경로탐색·추적 알고리즘 없음. if문 수준.
- **좁은 시야 보호 제약(중요):**
  - 몬스터는 **플레이어 가시 범위 밖에서만 스폰**(눈앞 젠 금지).
  - 몬스터 **이동 속도는 플레이어보다 느리거나 같게** 상한(좁은 시야에서 갑툭튀 즉사 방지).
  - 스폰 직후 **짧은 유예**(예: 등장 후 1~2초는 무해) 두어, 나타나자마자 닿는 상황 차단.

### 모드 (구현)

**현재 구현**: `matchOption: 300` (5분 제한 · 타임어택 단일)
- `MATCH_LIMIT_SEC = 300`
- 시간 초과 시 `gameWinner='실패'` → EscapeGameOver `outcome='timeout'`
- 성공 시 `outcome='win'` + 소요 시간 metric 카드
- 미로 크기 옵션 미노출 (default 크기 · seed로 다양성 확보)

**결정 로그**
- **타임어택 단일** 배포 — 기록 모드는 리더보드 인프라 필요 (미구현)
- 미로 크기 옵션은 spec `M2 게임 메인`엔 없어서 생략 (registry.matchOptions 단일값)

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **기본 가시 반경** → **2칸**(약 5×5). 1칸은 답답, 3칸+는 협동 강제 약화. 시야 아이템으로 확장 시 대비 큼.
2. **시야 아이템 효과** → 가시 반경 **+1~2칸**, 지속 **15초**. 발동 중 카메라 줌아웃 연동.
3. **속도 아이템** → 이동속도 **+40%**, 지속 **10초**.
4. **몬스터 속도** → 플레이어의 **90%**(항상 느림). 스폰은 가시 범위 밖 + 등장 후 **1.5초 무해**.
   - **현재 구현 튜닝** (사용자 피드백 반영):
     - Wander cadence `dt * 0.35` (기존 0.7 → 절반)
     - 이동 lerp `0.09` (기존 0.16 → 절반)
     - 방향 dwell `800 + Math.random() * 1600` (800-2400ms, 기존 400-1300ms의 배)
     - 순효과: 느긋한 배회 · 갑툭튀 완화
5. **몬스터 접촉 페널티** → 그 자리 **2초 스턴**(즉사 아님). 쉴드 보유 시 1회 무효.
   - **UI 피드백**: 스턴 시 bomb-red 토스트 (`몬스터에게 걸렸어요! 2초 스턴`) + 스파크 파티클 + `navigator.vibrate(120)`
6. **아이템 스폰 주기** → 평균 **8초**마다 1개, 좋은:나쁜 = **7:3**(나쁜 게 가끔이라 변수).
7. **미로 크기** → 소 15×15 / 중 25×25 / 대 35×35.
8. **타임어택 제한** → 소 90초 / 중 150초 / 대 240초.
9. **매치** → 협동이므로 대전 승패 없음. **기록 모드는 팀 최고기록 갱신**, 타임어택은 클리어/실패.

> 1·4·8은 특히 실측 의존 — "평균 몇 초 만에 만나는지 / 몬스터에 얼마나 막히는지" 재서 조정.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면             | 핵심 요소                                       |
| --- | ---------------- | ----------------------------------------------- |
| 1   | **로비 / 매칭**  | 2인 팀 구성, **모드·미로 크기 선택**            |
| 2   | **대기 / 준비**  | 시드·모드 표시, 준비 완료                       |
| 3   | **게임 메인**    | 카메라 팔로우 미로 + 좁은 시야 + 조작 + 진행 UI |
| 4   | **진행 상태 UI** | [합류 ✅/⬜] [열쇠 ✅/⬜] → [출구 열림] 전환    |
| 5   | **출구 안내**    | 조건 충족 시 출구 방향 화살표                   |
| 6   | **결과**         | 탈출 성공/실패, 소요 시간, 재시작               |
| 7   | **가이드/규칙**  | 위 A 섹션 (인게임 상시 열람)                    |

### 게임 메인(3번) 구성 요소

- **카메라 팔로우 미로** — 내 캐릭터 중앙 고정, 주변만 렌더
- **탐사 안개** — 미탐색=암흑 / 탐색완료=어둡지만 벽 보임 / 현재 시야=밝음
- **좌우상하 컨트롤** — 탭 또는 스와이프/방향키
- **진행 상태 UI** — 합류·열쇠 체크리스트 (상시)
- **아이템·몬스터** — 색 구분 아이템, 규칙이동 몬스터
- **출구 안내** — 조건 충족 후 방향 표시

### 서버/로직이 처리할 것

- **미로 생성기** — 시드 기반, 한 블록 폭 길. 양쪽 같은 미로(공정성). 크기는 모드값.
- **두 플레이어 좌표 동기화** — 서로의 위치를 주고받아 "합류" 판정.
- **탐사 안개 관리** — 각자 방문 칸 기록(벽 구조 유지 표시).
- **아이템 스폰/효과** — 주기 스폰, 색 구분, 효과 적용(시야·속도·쉴드·열쇠·재구성·출구이동·몬스터).
- **몬스터 이동** — 랜덤 방향 + 벽/주기 전환. 스폰·속도 안전 제약 적용.
- **탈출 조건 판정** — 합류 + 열쇠 → 출구 생성 → 함께 도달 시 클리어. 소요 시간 기록.
