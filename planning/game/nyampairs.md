# 냥냥 페어즈 (가칭) — 기획 정리서

> 2~4인 기억 대전. 뒤집힌 카드판에서 짝을 맞춰 가져간다. 하지만 카드를 열면 **위치가 모두에게 노출**되므로, 무엇을 열지가 곧 상대에게 정보를 주는 결정. 순수 암기가 아니라 **정보를 언제 흘리고 언제 회수할지**의 눈치 싸움. 특수 냥 카드가 판을 뒤집는다.

_가칭 후보: 냥냥 페어즈 / 짝꿍냥 / 기억의 발바닥_
_(추리·순발력·심리와 겹치지 않는 '기억+정보관리' 뇌. 공유 보드라 혼자 외우는 신경쇠약과 달리 대인 심리가 붙음)_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 뒤집힌 카드에서 **짝**을 찾아 가져가라. 많이 모은 사람이 승리 — 단, 남이 본 것도 기억한다.

### 화면

- **공유 카드판**(뒤집힌 카드 격자)을 전원이 함께 본다.
- 내 차례에 카드 **2장을 열어** 짝인지 확인한다. 열린 위치는 **모두가 본다.**

### 내 차례

1. 카드 **1장 오픈** → 잠깐 공개.
2. 카드 **1장 더 오픈**.
   - **짝이면** → 두 장 **내가 획득**, **한 번 더** 내 차례 진행(연속).
   - **짝이 아니면** → 다시 뒤집히고 **다음 사람 차례.**
3. 짝 맞춘 만큼 점수. 판이 비면 게임 종료.

### 특수 냥 카드 (짝을 맞추면 능력 발동)

| 카드 | 짝 맞추면 |
| --- | --- |
| 😼 도둑냥 | 상대가 가진 **짝 1쌍을 훔쳐** 온다 |
| 🔔 방울냥 | 남은 뒤집힌 카드 **위치를 살짝 섞는다**(전원 기억 리셋) |
| 👀 눈냥 | 원하는 카드 **1장을 나만 몰래** 미리 본다 |
| ⭐ 별냥 | **+2 보너스 점수** |

### 승리

- 카드판이 다 비면 → **모은 짝(점수)이 가장 많은 사람 승리.**

### 핵심 감각

- 남이 연 카드 위치를 외워두면 내 차례에 바로 짝을 딴다 → **정보를 준 셈.**
- 그래서 "짝을 모르는데 굳이 열어 정보만 주느냐"의 딜레마.
- 도둑냥·방울냥으로 앞서가던 사람을 흔든다.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2~4인.** 공유 카드판(짝수 장, 크기는 C 참고).
- 카드는 시드 기반으로 셔플·배치(전원 같은 판 — 단일 공유 보드라 동일).
- 대부분 **일반 짝 카드**(고양이 그림 종류별 2장) + 소수 **특수 냥 카드**(각 2장).
- 시작 시 전부 뒤집힘.

### 턴 진행 (순번 교대)

- 자기 차례에 **2장 오픈:**
  - **짝 성립** → 두 장 획득, 특수 카드면 능력 발동, **연속 턴**(한 번 더).
  - **불성립** → 두 장 원위치(뒤집힘), 턴 종료.
- 오픈은 **전원에게 공개**(일시적으로 그림 노출) → 기억 정보가 공유됨.
- 순번은 시계방향(시드로 첫 순번 결정).

### 특수 냥 카드 (짝 성립 시 1회 발동)

- 😼 **도둑냥:** 상대 1명 선택 → 그가 획득한 짝 1쌍을 가져옴(상대 없거나 빈손이면 불발). 획득 자체 점수는 별도.
- 🔔 **방울냥:** 현재 **뒤집힌 채 남은** 카드들의 위치를 시드 기반으로 재배치(맞춘 카드는 제외). 전원의 기억이 무효화 → 판을 흔드는 카드.
- 👀 **눈냥:** 남은 뒤집힌 카드 중 **1장을 골라 나만 몰래** 확인(위치·그림 파악). 다음 턴 유리.
- ⭐ **별냥:** 즉시 +2 보너스 점수(짝 획득과 별개).
- 특수 카드도 "짝"이므로 획득 시 연속 턴 규칙 동일 적용.

### 정보 공개 범위

- **공개:** 카드판 위치, 오픈되는 순간의 그림(전원), 각자 획득 짝 수(점수).
- **비공개:** 각자의 "기억"(별도 저장 안 함 — 순수 두뇌), 눈냥으로 본 내용.
- **오픈 로그(선택·초보 배려):** 직전 몇 턴에 어디서 무엇이 나왔는지 짧게 표시하는 보조 모드 on/off.

### 종료 & 승패

- 카드판이 **완전히 비면** 종료.
- **획득 점수 = (일반 짝 1점) + (별냥 보너스) + (특수 카드 짝도 1점).**
- 최다 점수 승. **동점** → 특수 카드를 많이 모은 쪽 → 그래도 같으면 공동 승(무승부).

### 왜 머리를 쓰는가 (설계 의도)

- **정보 딜레마:** 짝 위치를 모른 채 여는 두 번째 카드는 남에게 위치를 알려줄 위험. "언제 모험하고 언제 안전하게 아는 짝만 딸지."
- **기억 우위:** 남의 턴에 나온 카드까지 외운 사람이 앞선다 → 순수 집중력 보상.
- **판 흔들기:** 방울냥(기억 리셋)·도둑냥(점수 강탈)이 있어 단순 암기 최강자에게도 견제가 들어감 → 뒤처진 사람의 역전 여지.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **카드판 크기(인원별)**
   - **2인:** 6×4 = 24장(12쌍). 
   - **3인:** 6×6 = 36장(18쌍).
   - **4인:** 8×6 = 48장(24쌍).
   - (인원 늘수록 판을 키워 한 사람 독식 방지 + 기억 부담 균형)
2. **특수 카드 비율** → 전체 쌍의 약 **20%** 를 특수(도둑·방울·눈·별). 나머지는 일반 짝. 너무 많으면 기억 게임이 흐려짐.
3. **특수 카드 구성** → 도둑냥·방울냥·눈냥·별냥 각 1쌍 기본, 큰 판(4인)에선 별냥·눈냥을 1쌍씩 추가.
4. **오픈 노출 시간** → 카드 1장당 **약 1초** 공개 후 다음 동작. 외울 시간은 주되 늘어지지 않게.
5. **연속 턴 상한(선택)** → 무제한(짝 계속 맞추면 계속). 단 한 턴 독주가 심하면 "연속 3회 후 강제 턴 넘김" 옵션.
6. **방울냥 재배치 범위** → 남은 뒤집힌 카드 전체(맞춘 것 제외). 큰 판에선 파괴력이 크므로 1쌍만 등장.
7. **매치** → **단판제**(판이 완결형). 여러 판은 누적 점수 리그로 확장 가능.
8. **초보 보조** → '오픈 로그' 표시 on/off(기본 off, 캐주얼 모드 on).

> 1·2·4는 실측 핵심 — "평균 몇 턴에 판이 비는지 / 특수 카드가 승부를 얼마나 흔드는지" 재서 판 크기·특수 비율·노출 시간을 조정.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                              |
| --- | --------------- | ----------------------------------------------------- |
| 1   | **로비 / 매칭** | 2~4인 매칭, 방 생성, 인원·판 크기 표시                 |
| 2   | **대기 / 준비** | 시드·인원·규칙 표시, 준비 완료                         |
| 3   | **게임 메인**   | 공유 카드판 + 순번 표시 + 각자 점수 + 오픈 액션        |
| 4   | **오픈 연출**   | 카드 뒤집기 애니 + 짝 성립/실패 피드백                 |
| 5   | **특수 카드 연출** | 도둑냥/방울냥/눈냥/별냥별 다른 발동 연출             |
| 6   | **결과**        | 점수 순위, 각자 모은 짝·특수 카드, 재시작              |
| 7   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                           |

### 게임 메인(3번) 구성 요소

- **공유 카드판** — 뒤집힌 카드 격자, 오픈 시 그림 노출, 획득 카드는 자리 비움.
- **순번 표시** — 현재 차례 플레이어 강조, 연속 턴 표시.
- **점수 트래커** — 각자 모은 짝 수·특수 카드 보유.
- **오픈 대상 선택** — 내 차례에 카드 탭 → 1장씩 오픈.
- **특수 발동 UI** — 도둑냥(상대·짝 선택), 눈냥(카드 선택), 방울냥(자동), 별냥(자동).

### 서버/로직이 처리할 것

- **카드판 생성기** — 시드 기반 배치, 인원별 판 크기·특수 카드 비율대로.
- **오픈·짝 판정** — 2장 비교, 성립 시 획득·연속 턴, 특수 능력 트리거.
- **특수 능력 엔진** — 도둑(짝 이전)·방울(재배치 시드)·눈(비공개 확인)·별(점수).
- **순번·점수 관리** — 턴 교대, 연속 턴, 점수 집계, 종료·순위 판정.
- **공유 상태 동기화** — 오픈 위치·획득 결과를 전원에게 브로드캐스트(공유 보드라 상태 일치 필요).

### 통신

- 공유 보드라 **오픈 이벤트(카드 위치 1~2건) + 결과(획득/재배치)** 를 턴마다 브로드캐스트. 특수 카드 발동 시 추가 1건. → 턴당 소량. 실시간 물리 없음. 카드 뒷면 실제 그림은 서버/호스트가 보관해 치트 방지(오픈 시점에만 해당 카드 공개).

## 라인업에서의 위치

- **1번 코드네임: 모순** = 연역 추리 (대전)
- **2번 냥호 브레이커** = 귀납 추리 (대전)
- **3번 우다다 대시** = 순발력·조작 (대전)
- **4번 냥탈출** = 협동·소통 (협동)
- **신규 냥냥 페어즈** = **기억·정보관리** (2~4인) ← 추리(논리)·순발력(조작)·심리(속임)와 또 다른 '집중·암기' 뇌. 공유 보드라 혼자 외우는 신경쇠약과 달리 "정보를 언제 흘릴지"의 대인 심리가 얹힘.
- 공통: 가벼운 통신(오픈 위치 + 결과), 카드 격자라 Canvas 불필요, HTML/CSS로 고퀄 가능. 구현 난이도 가장 낮음(초경량).
