# 우다다 대시 (가칭) — 기획 정리서

> 1:1 고양이 러너. 좌우로만 피하며 최대한 멀리 간다. 각자 같은 맵을 달려 거리로 승부. 실시간 동기화 없이, 시작·종료 두 번의 통신만.

_가칭 후보: 우다다 대시 / 냥러너 / 나인라이프 러너_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 좌우로 피하며 최대한 멀리! 상대와 **같은 길**을 달려 거리로 승부.

### 화면

- 고양이는 **하단 중앙 고정.** 배경이 아래로 흐르며 전진하는 느낌.
- 위에서 장애물이 내려옴 → **좌우로 이동해 피하기.**

### 조작

- **좌 / 우 이동, 이것뿐.** (점프 없음)

### 모드 (방 만들 때 선택)

| 모드         | 끝나는 조건          | 점수                            |
| ------------ | -------------------- | ------------------------------- |
| **서바이벌** | 장애물에 부딪히면 끝 | 버틴 거리                       |
| **타임어택** | 제한 시간(60초)      | 그 안에 간 거리 (부딪히면 감속) |
| **스프린트** | 목표 거리 완주       | 걸린 시간 (짧을수록 승)         |

### 공정성

- 양쪽이 **완전히 같은 맵**을 달림 (장애물 배치 동일) → 순수 실력 승부.

---

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 탑다운 러너. 고양이 하단 중앙 고정, 배경 스크롤로 전진 표현.
- 조작: 좌/우 이동만 (레인 방식 또는 자유 좌우 — 아래 확정값 참고).
- 인원: **2인.** 각자 자기 화면에서 플레이(동시 진행 아님).

### 진행 흐름

1. 호스트가 방 생성 시 **모드 선택.**
2. 서버가 **맵 시드(seed)**를 생성해 양쪽에 전달 → 장애물 배치 동일.
3. 각자 자기 타이밍에 플레이 → 종료 시 **거리(또는 타임) 기록을 서버로 전송.**
4. 서버가 두 기록 비교 → 승자 판정.

- **통신은 시작(시드 수신) + 종료(기록 전송) 2회뿐.** 실시간 위치 동기화 없음.

### 모드별 종료 조건

- **서바이벌:** 장애물 1회 충돌 = 즉시 종료. 충돌 전까지 거리 = 점수.
- **타임어택:** 60초 경과 = 종료. 충돌 시 즉사 아님 → **일정 시간 감속(속도↓)** 페널티만. 60초간 누적 거리 = 점수.
- **스프린트:** 목표 거리(예: 1000m) 완주 = 종료. 충돌 시 감속. **걸린 시간이 짧을수록 승.**

### 장애물 & 맵

- 시드 기반으로 장애물 배치를 결정적으로 생성 → 같은 시드 = 같은 맵.
- 진행할수록 밀도·속도 상승(난이도 곡선).
- 고양이 테마 장애물: 물웅덩이, 굴러오는 실뭉치, 낮잠 자는 강아지, 상자, 화분 등.

### 아이템 (선택 요소, 자기 화면 한정)

- 상호 견제가 아니라 **자기 강화**만 (동기화 불필요 유지):
  - 🐟 간식 — 잠깐 무적 or 가속
  - 🧶 실뭉치 통과 — 점수 보너스
- 상대를 방해하는 아이템은 없음(통신 구조상 실시간 개입 불가). 순수 기록 경쟁.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **이동 방식** → **3레인 방식**(좌·중·우). 자유 좌우보다 판정이 명확하고 모바일 조작이 쉬움. 탭/스와이프로 레인 이동.
2. **기본 속도 / 가속** → 시작 속도 기준, **10초마다 +8%** 가속(상한 2.5배). 뒤로 갈수록 손에 땀.
3. **타임어택 시간** → **60초** (한 판이 부담 없고, 실력 차가 드러나기 충분).
4. **서바이벌 충돌** → **1회 즉사**(순수 긴장형). 단, 시작 후 **3초는 무충돌 워밍업**(초반 즉사 방지).
5. **타임어택/스프린트 충돌** → **1.5초 감속(속도 40%)** + 짧은 비틀거림 모션. 즉사 아님 → 만회 가능.
6. **스프린트 목표 거리** → **1200m** (약 60~90초 분량, 실력 따라 편차).
7. **매치** → **3판 2선승제.** 3판을 서로 다른 모드로 지정할 수도(서바이벌/타임어택/스프린트 각 1판) → 종합 실력 승부.
8. **동점 처리** → 거리·타임 완전 동일 시, 충돌 횟수 적은 쪽 승 → 그래도 같으면 무승부(재경기).

> 2·4·6은 특히 실측 의존 — 실제 플레이로 "평균 생존 시간 / 60초 도달 거리"를 재서 가속 곡선과 목표 거리를 맞추면 정확하다.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                                     |
| --- | --------------- | ------------------------------------------------------------- |
| 1   | **로비 / 매칭** | 1:1 매칭, 방 생성, **모드 선택**                              |
| 2   | **대기 / 준비** | 시드 수신, 모드·규칙 표시, 준비 완료                          |
| 3   | **게임 메인**   | 스크롤 배경 + 고양이 + 장애물 + 좌우 컨트롤 + 거리·타이머 HUD |
| 4   | **충돌 연출**   | 서바이벌(종료 연출) / 감속(비틀거림) 구분                     |
| 5   | **내 결과**     | 내 거리·타임, 기록 전송                                       |
| 6   | **매치 결과**   | 두 기록 비교, 승패, 판수 스코어, 재시작                       |
| 7   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                                  |

### 게임 메인(3번) 구성 요소

- **스크롤 배경** — 아래로 흐르는 트랙 (전진감)
- **고양이 캐릭터** — 하단 중앙 고정, 좌우 레인 이동 모션
- **장애물** — 시드 기반 등장, 레인별 배치
- **좌우 컨트롤** — 화면 좌/우 탭 또는 스와이프
- **HUD** — 현재 거리 / 남은 시간(타임어택) / 목표까지(스프린트)
- **아이템 이펙트** — 무적·가속 등 자기 강화 표시

### 서버/로직이 처리할 것

- **맵 시드 생성기** — 시드 → 결정적 장애물 배치. 같은 시드 = 같은 맵 (공정성 핵심)
- **난이도 곡선** — 거리에 따른 장애물 밀도·속도 산출
- **충돌 판정** — 레인 겹침 체크(가벼움). 모드별 결과(즉사/감속) 분기
- **기록 비교** — 두 거리·타임 수신 후 승자 판정, 동점 처리
- **매치 관리** — 판수, 모드 로테이션, 매치 승패
