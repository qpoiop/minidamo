# 룰셋 판도라 — 기획 정리서

> 2인 조건부 추리. 카드를 뒤집어 얻은 힌트로 폭탄 위치를 좁히지만, 규칙만으로는 100% 확정되지 않는다. 마지막은 추론 + 배짱.
>
> **구현 상태:** v1.2.0 라이브 (`src/features/games/bombhunt/`). thumbKind/코드는 `bombhunt`. 로비 라벨은 **룰셋 판도라**. 기존 이름 "코드네임: 모순 / 모순" 은 초기 아이디어 시절 명칭 · 문서 안에서는 새 이름과 병기.

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 뒤집힌 9장 중 **폭탄 1장**을 피하고, 정확히 찾아내면 승리.

### 카드 구성 (3×3, 9장)

| 폭탄 | 전체규칙 | 개인규칙 | 일반 |
| :--: | :------: | :------: | :--: |
| 1장  |   3장    |   3장    | 2장  |

- **폭탄** — 열면 즉시 패배
- **전체규칙** — 열면 양쪽 다 규칙 획득
- **개인규칙** — **연 사람만** 규칙 획득 (상대는 "먹었다"는 것만 봄)
- **일반** — 정보 없이 턴 넘어감
- 폭탄 빼고 전부 안전. 카드 앞면으로 종류가 구분됨.

### 내 턴에 할 수 있는 것 (셋 중 하나)

1. **뒤집기** — 카드 1장 열기 (폭탄이면 패배)
2. **턴 넘기기** — 라운드당 1회, 아무것도 안 열고 넘김
3. **폭탄 찾기** — 폭탄 지목 → 맞으면 **승리**, 틀리면 **패배**

### 규칙은 4종류

| 종류         | 예시 문구                           | 하는 일                                            |
| ------------ | ----------------------------------- | -------------------------------------------------- |
| **관계형**   | "폭탄은 ○○ 옆에 있다"               | 폭탄의 위치 관계                                   |
| **조건형**   | "○○가 안전이면 폭탄은 △△일 수 있다" | 조건 성립 시 가능성                                |
| **소거형**   | "○○는 폭탄이 아니다"                | 한 칸 지움                                         |
| **배제형** ✦ | "폭탄은 ○○ 줄에 없다"               | 여러 칸을 한 번에 배제 (판당 1장만 등장·특별 연출) |

> 규칙이 참조하는 카드가 **이미 열려 있으면 바로**, 아직 안 열렸으면 **그 카드가 열리는 순간** 효과가 생긴다.

### 핵심 감각

- 카드를 열수록 규칙과 정보가 쌓여 폭탄이 좁혀진다.
- 하지만 **규칙만으로 폭탄이 1칸으로 확정되진 않는다.** 끝은 늘 판단과 배짱.
- 상대가 무슨 개인규칙을 아는지는 모른다. "언제 지를까"의 눈치싸움.

### 라운드 종료

폭탄만 남으면(안전 카드 다 열림) → 전부 다시 섞고, 규칙 초기화 → 다음 라운드.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 3×3 = 9칸, 9장 전부 뒤집힌 채 시작.
- 구성: 폭탄 1 / 전체규칙 3 / 개인규칙 3 / 일반 2.
- 카드 앞면은 열렸을 때 종류가 시각적으로 구분됨 (색·모양·이펙트).

### 턴 진행 (2인 교대)

자기 턴에 아래 3택 1을 수행하고 턴 종료.

**① 뒤집기** — 뒤집힌 카드 1장 선택해 오픈

- 폭탄 → 즉시 패배 (게임 종료)
- 전체규칙 → 규칙 공개. **양쪽 모두** 내용 획득·적용
- 개인규칙 → **연 사람만** 내용 획득. 상대는 카드 종류(개인규칙)만 보임, 내용은 비공개
- 일반 → 정보 없음, 턴 넘어감
- 규칙·일반 모두 "안전"이라 열어도 죽지 않음

**② 턴 넘기기** — 라운드당 1회. 아무 카드도 안 열고 턴만 넘김

**③ 폭탄 찾기 (선언)** — 남은 뒤집힌 카드 중 폭탄을 지목

- 정확히 폭탄 → 즉시 승리
- 일반/규칙 카드 → 즉시 패배

### 규칙 시스템

- 규칙은 **등급(별) 없음**, **타입**으로 구분: 관계형 / 조건형 / 소거형 / 배제형.
- 전부 **추론형(정황 증거)** 성격 → 규칙 하나로는 확정 못 함.
- **참조 카드 발동 조건:** 규칙이 가리키는 카드가 이미 열려 있으면 즉시 효과, 아직 안 열렸으면 그 카드가 열리는 순간 발동(잠자는 규칙).
- **관계형은 참조 대상을 단일 카드로 고정** ("규칙카드 옆" 같이 여러 장을 기준 삼는 문구 금지 — 범위가 사실상 전체가 되어 무의미).
- **배제형은 판당 딱 1장**만 등장. 광역 배제라 강하므로 희소성으로 통제. 등장 시 특별 연출.

### 불변 원칙 (밸런싱의 핵심)

- **어떤 규칙 조합도 폭탄을 1칸으로 100% 확정시키지 않는다.** (후보 항상 2장 이상)
- 후반에 확률이 높아지는 것은 **소거(열린 카드가 늘어 남은 카드가 줄기) 때문**이지, 규칙이 정답을 찍어줘서가 아니다.
- 확률 곡선 목표:
  - 초반(6~7장 남음): 후보 넓음. 지르면 도박.
  - 중반(4~5장): 규칙 + 소거가 겹쳐 눈에 띄게 좁혀짐.
  - 후반(3장 이하): 자연히 50%+. 정보 싸움은 거의 끝, 타이밍·배짱 승부.

### 정보 열람

- 턴과 무관하게 언제든 "몇 번째 턴에 어떤 규칙이 나왔는지" 히스토리 확인 가능 (내 개인규칙 + 공개된 전체규칙/배제형).

### 협동/경쟁 구조

- 정보(규칙)는 상황에 따라 공유될 수 있으나, 승자는 한 명(폭탄 하나) → 완전 협동은 성립 안 함.
- **개인규칙 공유 여부는 시스템이 관여하지 않음** (플레이어끼리 말로 공유하든 속이든 자유).

### 라운드 순환

- 폭탄 제외 8장이 다 열리면 → 전 카드 재셔플, 규칙 전부 초기화, 다음 라운드 시작.
- (승부가 나기 전, 폭탄만 남는 상황은 실제로는 드묾 — 대부분 그 전에 폭탄 찾기가 나옴)

## C. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면                  | 핵심 요소                                      |
| --- | --------------------- | ---------------------------------------------- |
| 1   | **로비 / 매칭**       | 1:1 상대 매칭, 방 생성·입장                    |
| 2   | **게임 보드 (메인)**  | 3×3 카드 그리드 + 턴/상태 + 액션               |
| 3   | **카드 오픈 연출**    | 일반 / 규칙 / 배제형(특별) / 폭탄별 다른 연출  |
| 4   | **내 개인규칙 패널**  | 내 폰에만 보이는 획득 규칙 목록                |
| 5   | **규칙 히스토리**     | 턴별 규칙 로그, 언제든 열람                    |
| 6   | **폭탄 찾기 확인**    | 지목 → "정말 이 카드?" 재확인 (돌이킬 수 없음) |
| 7   | **라운드 전환(셔플)** | 셔플·규칙 초기화 연출                          |
| 8   | **결과 (승/패)**      | 승패 표시, 폭탄 위치 공개, 재시작              |
| 9   | **가이드/규칙**       | 위 A 섹션 내용 (인게임 상시 열람)              |

### 게임 보드(2번) 화면 구성 요소

- **3×3 카드 그리드** — 뒤집힌 카드(선택 가능) / 열린 카드(종류 표시)
- **턴 표시** — 내 턴 / 상대 턴, (선택) 타이머
- **상대 상태 요약** — 상대가 획득한 규칙 종류·수 (개인규칙 n장, 배제형 획득 여부). 내용은 비공개
- **내 개인규칙 요약** — 나만 보이는 규칙 (탭하면 4번 패널)
- **공개 규칙 영역** — 전체규칙·배제형 등 공개 정보
- **액션 버튼 3개** — 뒤집기(카드 선택 모드) / 턴 넘기기(라운드당 1회, 소진 시 비활성) / 폭탄 찾기
- **규칙 로그 버튼** — 5번 히스토리 열기

### 서버/로직이 처리할 것

- **카드 배치기** — 9칸에 폭탄1·전체3·개인3·일반2 무작위 배치 + 각 규칙 카드에 규칙 문구 할당
- **규칙 세트 생성기** — 배제형 1장 보장 + 나머지 5장(관계형/조건형/소거형) 조합
- **정합성 검증기** — 생성된 규칙 세트가 **폭탄을 1칸으로 확정시키지 않는지**(후보 ≥2) 자동 확인 (핵심)
- **규칙 발동 엔진** — 참조 카드 오픈 상태에 따라 규칙 활성/비활성 판정
- **턴/상태 관리** — 턴 교대, 패스 사용 여부, 승패 판정, 라운드 순환

## D. 확정 사항 (구현 기준)

1. **배제형 카드 소속** → **매판 랜덤** (전체규칙일 수도, 개인규칙일 수도). "이번 판 배제형이 개인으로 떴다 → 먼저 먹는 사람이 크게 유리" 같은 판별 변수 발생.
2. **규칙 6장 타입 구성** → 배제형 1장(랜덤 소속) + 관계형 2 + 조건형 2 + 소거형 1.
3. **패스** → **게임당 1회** (라운드가 아니라 게임 전체에서 한 번).
4. **인원** → **2인 고정.**

## E. 규칙 문구는 어떻게 만드나 (템플릿 → 배치 → 검증)

문구를 매판 손으로 쓰는 게 아니라, **타입별 템플릿 뱅크**에서 뽑아 실제 카드 배치에 값을 채우고, 정합성 검증기로 거른다.

### 1단계 — 타입별 문구 템플릿 뱅크

`{X}`, `{줄}`, `{영역}`은 매판 카드 배치에 맞춰 채워지는 슬롯.

**관계형** (폭탄과 특정 1장의 위치 관계)

- "폭탄은 `{X}`번 카드와 **인접**해 있다"
- "폭탄은 `{X}`번 카드와 **같은 줄**에 있다"
- "폭탄은 `{X}`번 카드와 **같은 열**에 있다"
- "폭탄은 `{X}`번 카드와 **대각선** 방향에 있다"

**조건형** (조건 성립 시 가능성 — "~일 수 있다")

- "`{X}`번이 안전이면, 폭탄은 `{영역}`에 있을 수 있다"
- "`{X}`번이 안전이면, 폭탄은 `{Y}`번과 가까이 있을 수 있다"

**소거형** (한 칸 지움)

- "`{X}`번은 폭탄이 아니다"

**배제형** ✦ (판당 1장, 광역 배제, 특별 연출)

- "폭탄은 `{줄}`에 없다" (윗줄/가운뎃줄/아랫줄)
- "폭탄은 `{열}`에 없다" (왼/가운데/오른)
- "폭탄은 **모서리**(1·3·7·9)에 없다"

### 2단계 — 배치에 맞춰 값 채우기

1. 폭탄 위치를 무작위로 정한다 (예: 7번).
2. 각 규칙 카드에 템플릿을 뽑아, **폭탄 위치에 대해 참(true)이 되도록** 슬롯을 채운다.
   - 예: 폭탄 7번 → 관계형 "폭탄은 4번과 인접해 있다"(4-7 인접, 참) / 소거형 "3번은 폭탄이 아니다"(참).
3. 참조 카드가 규칙 카드 자신을 가리키지 않게, 슬롯끼리 모순되지 않게 정리.

### 3단계 — 정합성 검증 (자동, 필수)

생성한 6장 규칙을 전부 참이라 가정하고, 9칸 각각이 폭탄일 수 있는지 계산 → **살아남는 후보가 2칸 이상**이어야 통과. 1칸으로 확정되면 폐기하고 재생성.

> 이 3단계 파이프라인 덕에, "규칙 단독으로 100% 확정 불가"라는 불변 원칙이 매판 자동으로 지켜진다. 문구를 사람이 검수할 필요가 없다.
