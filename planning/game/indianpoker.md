# 모디언트릭 — 기획 정리서

> 2인 베팅 심리 대전. 각자 숫자 카드 한 장을 받는데 **자기 카드는 못 보고 상대 카드만 보인다.** 상대 카드가 낮으면 내 카드는 높을 확률이 크다 — 하지만 상대도 내 카드를 보며 같은 계산을 한다. 서로의 베팅에서 정보를 읽어 콜/폴드를 결정하는, 확률과 블러핑의 순수 두뇌 싸움. 여기에 **바퀴벌레 포커식 '선언·의심'과 공개 버림패 카운팅**을 얹어 2인 순수 운을 실력으로 바꾼다. (인디언 포커 + 바퀴벌레 포커 융합)

_이름: 모디언트릭 (인디언 포커 + 모, 상대를 속이는 trick)_
_(라인업에서 빠진 '심리·베팅' 축. 냥말 블러핑이 '정체 은폐'라면, 이건 '보이는 정보로 안 보이는 내 패를 역추론'하는 확률 심리. 2인에서 가장 순도가 높음)_

> **구현 상태:** v1.0.0 라이브 (`src/features/games/ditrick/`, `Ditrick.tsx`). thumbKind/코드는 `indianpoker`. 2인 · 판당 카드 1장 · 앤티/체크/콜/레이즈/폴드. matchOption = 총 판 수(9/15/21), matchOption2 = 시작 칩(20/30/50). MVP 는 인디언 포커 파트만 · 「선언·의심」 (바퀴벌레 포커 융합) + 버림패 카운터 UI 는 다음 사이클.

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 내 카드는 안 보이고 **상대 카드만 보인다.** 상대 것과 베팅을 읽어, 내 숨은 카드가 이길지 판단하라.

### 화면

- 내 앞의 카드는 **뒷면(?)** — 나는 못 봄. 상대에게는 앞면으로 보임.
- 상대 카드는 나에게 **앞면**으로 보임. (서로 상대 것만 보는 구조)
- 가운데 **판돈(팟)**, 각자 **칩 스택**이 보인다.

### 한 판 흐름

1. 둘 다 **기본 베팅(앤티)** 낸다 → 각자 카드 1장 배분(자기 것 못 봄).
2. **베팅 라운드:** 번갈아 [체크/콜] · [레이즈] · [폴드].
   - 누가 **폴드**하면 → 상대가 팟 획득(자기 앤티만 잃음).
   - 서로 **콜**로 맞으면 → 양쪽 카드 공개, **숫자 높은 쪽이 팟 획득.**
3. 다음 판. 칩을 다 잃거나 정해진 판 수가 끝나면 매치 종료.

### 핵심 감각

- 상대 카드가 **낮으면** 내 카드는 평균적으로 높음 → **콜/레이즈** 유리.
- 하지만 상대는 **내 카드를 본다** → 내가 높으면 상대가 폴드함. 상대가 안 죽고 세게 나오면 "내 카드가 낮다는 신호"일 수 있음.
- 그래서 가끔 **블러핑**(낮은 상대에 크게 질러 폴드 유도)이 통한다. 읽기와 속이기의 균형.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2인 전용.**
- 덱: 숫자 카드 **1~10, 각 4장 = 40장**(동률 존재로 심리 폭↑). 방 옵션 **1~15 각 2장**(변별력↑).
- 시작 칩: 각 **30개.** 앤티 **1개.**
- 시드로 셔플·선공 결정. 카드의 실제 값은 서버/호스트가 보관(치트 방지), 각자에겐 **상대 것만** 전송.

### 한 판 상세

1. **앤티:** 양쪽 칩 1씩 팟에.
2. **배분:** 각자 1장(비공개=자기 것, 공개=상대에게). 나는 상대 카드 값을 안다.
3. **베팅(번갈아, 선공부터):**
   - **체크:** 추가 베팅 없이 넘김(양쪽 체크면 즉시 공개).
   - **콜:** 상대 베팅액 맞춤(맞으면 공개로).
   - **레이즈:** 현재액 + 증액(최소 1, 상한은 C).
   - **폴드:** 기권 → 상대가 팟 가져감. 판 종료.
   - **선언:** (레이즈 대신) 내 안 보이는 카드에 주장을 걸고 상대의 믿다/의심을 부름 → 아래 '2인 특화 장치' 참조. 한 판 1회.
4. **공개(쇼다운):** 양쪽 카드 오픈 → **높은 숫자 승** → 팟 획득.
   - **동률:** 팟을 반씩(홀수 칩은 선공에 +1) 또는 방 옵션 "무승부 판 무효·재배분".
5. 칩 이동 후 다음 판(선공 교대).

### 2인 특화 장치 (바퀴벌레 포커 융합 — 운을 실력으로)

순수 인디언 포커는 2인에서 한 장 승부라 운 스윙이 크다. 아래 두 장치로 **읽기·기억·심리**의 실력 비중을 끌어올린다.

- **공개 버림패 카운팅:** 매 판 쇼다운/폴드로 결판난 카드는 **가운데 공개 버림패 줄**에 앞면으로 쌓인다(다음 셔플 전까지 유지). 덱이 1~10 각 4장이므로, 나간 카드를 세면 "지금 상대 카드가 3인데, 3은 이미 2장 나갔고 높은 수가 덱에 많이 남았다 → 내 숨은 카드가 이길 확률"을 **정확히 계산**할 수 있다. 운이 아니라 카운팅·확률 실력이 이긴다. (랭크전은 자동 카운터 off = 순수 기억, 캐주얼은 on.)
- **선언·의심(바퀴벌레 포커 메커닉):** 자기 차례에 일반 레이즈 대신 **[선언]**을 택할 수 있다. 내 **안 보이는** 카드에 대해 주장을 건다 — 예: "내 카드가 상대보다 높다" 또는 "내 카드는 7 이상". 스테이크(칩)를 걸고 선언하면, **내 카드를 볼 수 있는 상대**가 [믿다] 또는 [의심]으로 응수한다.
  - **믿다:** 상대가 주장을 인정하고 물러남 → 선언자가 현재 팟 획득(상대는 건 칩 손실). 사실상 상대의 폴드.
  - **의심:** 즉시 쇼다운 → 선언이 **참이면 선언자**가 (스테이크만큼 커진) 팟 획득, **거짓이면 의심한 상대**가 획득.
  - 핵심 긴장: 선언자는 자기 카드를 **모르는 채** 주장하고, 판정 정보를 **쥔 쪽(상대)**이 믿을지 의심할지 고른다. 바퀴벌레 포커의 "못 보는 사람이 걸고, 아는 사람이 판단한다" 구조 그대로 → 상대의 카운팅·성향을 역이용한 **의도적 허풍**이 통한다.

### 종료 & 승패

- **칩 전부 획득**(상대 0) → 즉시 승리, **또는**
- **정해진 판 수(기본 15판) 후 칩 많은 쪽 승**(변별력·시간 관리). 방에서 택1.
- 판마다 승패가 쌓여 **운이 평균으로 수렴** → 실력(읽기·베팅)이 드러남.

### 왜 머리를 쓰는가 (설계 의도)

- **베이지안 추론:** 상대 카드 값 + 남은 덱으로 "내 카드가 이길 확률"을 계산.
- **신호 읽기:** 상대의 베팅 크기·속도가 곧 내 카드에 대한 상대의 평가 → 역이용.
- **블러핑 균형:** 항상 정직하면 읽힘. 낮은 상대에 가끔 지르는 세미블러프로 상대 콜 성향을 무너뜨림.
- **카운팅(운→실력):** 공개 버림패로 남은 덱을 추적해 "내 카드가 이길 확률"을 근사가 아닌 정확값으로 계산. 기억·확률이 곧 승률.
- **선언·의심의 메타:** 선언은 못 보는 내 패에 거는 허풍. 상대가 카운팅으로 "저 선언 거짓"이라 판단해 의심하도록 유도하거나, 반대로 진짜일 때 의심을 유도해 팟을 키운다. 상대의 판단을 읽는 2차 심리.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **덱 구성** → 기본 **1~10 각 4장(40)**. 동률이 생겨 심리 여지↑. 변별 원하면 1~15 각 2장.
2. **시작 칩 / 앤티** → 칩 **30**, 앤티 **1**. 앤티가 작아 여러 판 지속.
3. **레이즈 상한** → 한 판 **팟의 2배 또는 남은 칩**까지(무한 레이즈 방지). 올인 허용.
4. **베팅 라운드 상한** → 레이즈 왕복 **최대 3회**(늘어짐 방지) 후 강제 콜/폴드.
5. **승리 방식** → 기본 **15판 후 칩 우세**(예측 가능한 길이). 옵션 "파산 즉시 종료".
6. **소프트 타이머** → 판단 1회당 **15초**. 초과 시 자동 체크(가능하면)/아니면 폴드.
7. **동률 처리** → 팟 분할(홀수는 선공 +1). 옵션 무효·재배분.
8. **버림패 카운터** → 캐주얼 **on**(나간 카드 자동 집계 패널), 랭크전 **off**(순수 기억). 버림패 줄 자체는 항상 공개.
9. **선언 스테이크** → 최소 1 ~ 팟의 2배(레이즈 상한과 동일). 의심 시 그 스테이크만큼 팟 확대. 한 판 **선언 1회**로 제한(남발·늘어짐 방지).

> 1·2·5는 밸런스 핵심 — "몇 판에 실력차가 칩으로 벌어지는지"를 재서 덱·칩·판 수를 맞춘다. 판이 너무 스윙하면 판 수를 늘려 평균화.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                              |
| --- | --------------- | ----------------------------------------------------- |
| 1   | **로비 / 매칭** | 2인 매칭, 방 생성, 덱·승리방식(파산/판수) 설정         |
| 2   | **대기 / 준비** | 시드·칩·규칙 표시, 준비 완료                           |
| 3   | **게임 메인**   | 내 뒷면 카드 + 상대 앞면 카드 + 팟 + 양쪽 칩 + 베팅 액션|
| 4   | **베팅 연출**   | 칩 이동 애니, 레이즈/콜/폴드 라벨                      |
| 5   | **공개 연출**   | 양 카드 오픈 → 승자 팟 획득 애니                       |
| 6   | **결과**        | 매치 승패, 판별 히스토리, 재시작                       |
| 7   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                           |

### 게임 메인(3번) 구성 요소

- **내 카드(뒷면)** — 항상 "?" 표시. 상대에게만 값이 보임을 명확히 안내.
- **상대 카드(앞면)** — 나에게 값 노출.
- **팟·칩 스택** — 실시간 숫자 + 스택 높이.
- **베팅 액션 바** — [체크/콜] [레이즈 +슬라이더] [폴드] [올인] **[선언]**.
- **베팅 히스토리** — 이번 판 액션 로그(누가 얼마 레이즈했는지).
- **공개 버림패 줄** — 지난 판들에서 결판난 카드가 앞면으로 누적. (캐주얼) 숫자별 소진 카운터 패널 on/off.

### 인게임 안내·경고·피드백 장치 (모바일 화면 기준)

- **정보 방향 안내:** 첫 진입 시 "내 카드는 나만 못 봐요 — 상대는 봅니다" 화살표 온보딩. 내 카드 위 상시 눈금 아이콘(👁️상대만).
- **차례·잠금:** 내 베팅 차례에만 액션 바 활성, 상대 차례엔 비활성 + "상대가 고민 중…" 표시.
- **레이즈 슬라이더 가드:** 최소·최대(상한/올인) 범위 밖은 잠금. 남은 칩 초과 시 자동 올인 스냅 + "가진 칩 전부입니다" 안내.
- **올인 확정 경고:** [올인] 탭 시 "칩 전부를 겁니다. 지면 파산할 수 있어요" 확인 모달(파산 즉시종료 모드에서 특히).
- **칩 부족 경고등:** 내 칩이 앤티+최소콜보다 적어지면 스택이 **붉게 점멸** + "다음 판이면 파산 위험" 배너.
- **소프트 타이머:** 15초 링, 10초부터 노랑, 3초 진동/삐. 초과 시 "시간 초과 — 자동 체크/폴드" 토스트로 결과 고지.
- **블러핑 배려(정보 누수 방지):** 상대 화면엔 내 **고민 시간·손떨림 없이 최종 액션만** 표시(타이핑/드래그 중간상태 미전송) → 실물 이마빵의 "표정 읽기"를 UI로 못 훔치게, 순수 베팅 패턴만 남김.
- **선언·의심 2단계 확정:** [선언] 탭 → 주장 유형("상대보다 높다"/"7 이상" 등) + 스테이크 슬라이더 미리보기 → [선언 확정]. 상대 화면엔 [믿다]/[의심] 큰 버튼 + "상대 주장이 참이면 상대 승, 거짓이면 당신 승" 요약. 오탭 방지 재확인.
- **카운팅 보조 토글:** 캐주얼 모드 버림패 카운터 패널(숫자별 남은 장수) 노출. 랭크전엔 잠금(버림패 줄만 보여 순수 기억). "이 판은 카운터 없이 — 기억으로 승부" 안내.
- **선언 정보 누수 방지:** 선언자가 주장 유형을 고르는 중간 상태는 상대에 미전송(최종 선언만). 표정 훔치기 차단(기존 블러핑 배려와 동일 원칙).
- **공개 연출 고지:** 쇼다운 시 양 카드와 승패 사유("8 > 5" 또는 "선언 '높다' 참") 명확 표기 → 왜 졌는지 학습.
- **네트워크:** 상대 지연 시 스피너, 끊김 시 "재접속 대기"(판 상태는 서버 보관값으로 복원, 진행 중 판은 무효 처리 옵션).

### 서버/로직이 처리할 것

- **덱·배분기** — 시드 셔플, 각자 1장, **자기 값은 자기에게 숨김**(상대에게만 전송) — 치트 방지 핵심.
- **베팅 상태기** — 팟·칩·레이즈 왕복 카운트·유효 액션 검증.
- **쇼다운 판정** — 값 비교(동률 처리), 팟 이동.
- **선언 판정** — 선언 유형(상대보다 높다/N 이상 등)을 실제 카드값과 대조해 참·거짓 산출, 믿다/의심에 따른 팟 이동. 단순 비교 로직(AI 아님).
- **버림패·카운터** — 결판 카드 공개 더미 관리, (캐주얼) 숫자별 소진 집계. 셔플 시 리셋.
- **매치 관리** — 판 수/파산 조건, 선공 교대, 승패.

> **AI 불필요 근거:** 콘텐츠는 **숫자 카드(정적)**뿐. 시스템은 셔플·베팅 규칙·숫자 비교만. 상대의 심리·블러핑 해석은 전부 사람 몫. LLM 불필요.

### 통신

- **판당: 앤티·배분 브로드캐스트(상대 카드값만 각자에게) + 베팅/선언 액션 왕복(각 1건) + 믿다·의심 응수 1건 + 쇼다운 결과 1건.** → 판당 소량. 실제 카드값은 서버 보관, 쇼다운 시점에만 양쪽 공개. 버림패 공개 갱신은 결판 시 1건 브로드캐스트.
