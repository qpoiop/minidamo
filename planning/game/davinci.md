# 모빈치코드 — 기획 정리서

> 2인(확장 3~4인) 숫자 추리 대전. 각자 **오름차순으로 정렬된 숨은 숫자 타일**을 들고, 상대의 타일이 몇인지 하나씩 맞혀 간다. 맞히면 그 타일이 공개되고, **틀리면 내가 방금 뽑은 타일이 공개되는** 리스크. 정렬 순서·공개된 타일·상대 반응이 전부 단서. 모든 타일이 공개된 사람은 탈락. (다빈치 코드 기반)

_이름: 모빈치코드 (다빈치→빈치 + 모)_
_(라인업의 모순(연역·조건부 규칙 추리)과는 완전히 다른 뇌 — 모순은 '주어진 규칙으로 폭탄 칸을 좁히는' 논리, 이쪽은 '정렬 제약 + 공개 정보 전파 + 오답 리스크'로 숨은 숫자를 좁히는 확률·리스크 추리. 겹치지 않음)_

> **구현 상태:** v1.0.0 라이브 (`src/features/games/vinci/`, `deck.ts` · `Vinci.tsx`). thumbKind/코드는 `davinci`. 2인 · 시작 손 4장 · 26장 세트(검정 0-11, 흰색 0-11, 조커 2). MVP 정렬은 자동, 조커 위치 수동 지정은 다음 사이클. 다인전(3~4인)은 roadmap.

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 상대의 **숨은 숫자 타일**을 하나씩 맞혀라. 맞히면 상대 것이 열리고, 틀리면 **내 타일이 열린다.** 다 열린 사람 탈락.

### 화면

- 각자 앞에 **숫자 타일 줄**(오름차순). 내 타일은 **숫자가 나에게만** 보이고, 상대에겐 **뒷면·위치만** 보인다.
- 공개된(맞혀진/실패로 열린) 타일은 **앞면**으로 전원에게 보인다.

### 타일 규칙

- 검정 0~11, 흰색 0~11 (+ 조커 2개). **같은 숫자면 검정 < 흰색**으로 정렬.
- 항상 **작은 수 → 큰 수** 순서로 줄 세운다. 새로 뽑은 타일도 제자리에 끼워 넣는다(위치가 힌트가 됨).

### 내 턴 흐름

1. 가운데 더미에서 **타일 1장 뽑음**(나만 봄, 아직 비공개로 손에 듦).
2. 상대 타일 하나를 **지목 + 숫자 선언**("왼쪽에서 2번째 = 7").
   - **맞음** → 그 타일 공개. **한 번 더 추리**하거나 **멈추기** 선택.
   - **틀림** → 방금 뽑은 타일을 **내 줄에 앞면으로** 끼운다(공개). 턴 종료.
3. 멈추면 뽑은 타일을 **비공개로** 제자리에 넣고 턴 종료.

### 탈락 & 승리

- 자기 타일이 **전부 공개**되면 탈락. **마지막까지 숨은 타일이 남은 사람 승.**

### 핵심 감각

- 공개된 숫자 + 정렬 순서로 **가능한 값의 범위**를 좁힌다(예: 왼쪽이 3이고 오른쪽이 8이면 그 사이 칸은 4~7).
- 연속 성공으로 몰아붙일지, 애매하면 멈춰 **내 타일 공개를 피할지**의 리스크 판단.
- 새로 끼운 타일의 **위치**가 그 값의 대략 범위를 상대에게 흘린다.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2인 기본**(확장 3~4인 가능).
- 타일: **검정 0~11(12) + 흰색 0~11(12) + 조커 2 = 26장.**
  - 정렬: 숫자 오름차순, **동수는 검정 먼저(검정<흰색).**
  - **조커:** 아무 위치에나 놓을 수 있고, 공개 전까지 값이 '가변'(놓은 위치로 위장). 지목 시 "조커"라고 선언해야 맞음.
- 각자 시작 타일 **4장**(2인). 나머지는 더미. 시드로 배분(자기 타일 값은 자기만·서버 보관).
- 각자 자기 타일을 **오름차순 비공개**로 세팅.

### 턴 진행 (순번 교대)

1. **드로우:** 더미에서 1장(나만 확인, 손에 비공개로 듦). 더미가 비면 드로우 생략하고 바로 추리.
2. **추리:** 상대(다인전이면 대상 1명) 타일 1개 지목 + 값 선언.
   - **정답:** 해당 타일 앞면 공개. 이어서 **[계속] 또는 [멈춤]**.
     - **계속:** 손의 타일을 아직 비공개로 든 채 다시 추리(연속 성공 가능, 리스크 누적).
     - **멈춤:** 손의 타일을 **비공개**로 정렬 위치에 삽입 → 턴 종료.
   - **오답:** 손의 타일을 **앞면 공개**로 정렬 위치에 삽입(내 정보 손실) → 턴 종료.
3. 상대가 타일 전부 공개되면 탈락. 다음 사람.

### 정렬·삽입·조커 상세

- 새 타일은 항상 규칙대로 제자리 삽입(값+색 기준). **위치 자체가 공개 정보**(뒷면이라도 몇 번째인지 보임).
- **조커**는 소유자가 삽입 시 원하는 위치에 넣을 수 있음(정렬 위장). 공개되면 그 위치에 고정. 지목은 "조커"로만 정답.
- 이미 공개된 타일은 재지목 불가.

### 종료 & 승패

- **2인:** 상대 4장 전부 공개 → 상대 탈락 → 나 승.
- **다인전:** 탈락자 순차 발생, **최후 1인 승.** (누군가 탈락해도 게임 계속)
- 무승부: 구조상 없음(공개는 1장씩 순차).

### 왜 머리를 쓰는가 (설계 의도)

- **제약 전파(정렬이 곧 추리 엔진):** 오름차순 규칙이 없으면 숨은 타일은 그냥 무작위 숫자라 순수 운·찍기가 된다. 정렬 제약이 있기 때문에 "왼쪽이 3, 오른쪽이 8이면 사이 칸은 4~7" 처럼 공개 타일 + 색 규칙으로 각 숨은 칸의 **가능 값 집합**을 논리로 좁힐 수 있다. 즉 정렬 제약은 재미를 줄이는 게 아니라 **추리를 성립시키는 핵심 장치**다.
- **리스크 관리:** 연속 성공은 달콤하지만, 확신 없이 계속하면 오답 → 내 타일 공개. 언제 멈출지가 실력.
- **정보 은닉:** 내 새 타일 위치가 힌트를 흘리므로, 조커·배치로 상대의 추론을 흐린다.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **타일 세트** → 검정 0~11 + 흰색 0~11 + 조커 2 = **26장**(다빈치 코드 표준). 색 2계열로 동수 변별.
2. **시작 손** → **2인 4장**, 3인 4장, 4인 3장(더미 유지). 많을수록 판 길이·추리량↑.
3. **연속 추리 상한(선택)** → 무제한(맞히면 계속). 독주 심하면 "연속 3회 후 강제 멈춤" 옵션.
4. **턴 제한시간** → 추리 1회 **25초**(계산 시간 필요). 초과 시 자동 멈춤(뽑은 타일 비공개 삽입).
5. **매치** → **단판제**(탈락 구조로 완결형). 여러 판 누적 승점 리그 옵션.
6. **추리 보조(선택)** → '가능 값 하이라이트'(공개 정보로 각 칸 후보 자동 계산) on/off. 기본 off(순수 계산), 캐주얼 on.

> 2·4는 실측 핵심 — "몇 장·몇 초가 적정 추리 부담인지" 재서 시작 손·제한시간을 맞춘다.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                                |
| --- | --------------- | ------------------------------------------------------- |
| 1   | **로비 / 매칭** | 2~4인 매칭, 방 생성, 시작 손·보조 설정                    |
| 2   | **대기 / 준비** | 시드·인원·규칙 표시, 준비 완료                            |
| 3   | **게임 메인**   | 내 타일(값 보임)·상대 타일(뒷면+위치)·더미·공개 타일·드로우|
| 4   | **추리 UI**     | 상대 타일 지목 → 숫자/조커 선택 → 확정                    |
| 5   | **판정 연출**   | 정답=상대 타일 공개 / 오답=내 타일 공개                   |
| 6   | **결과**        | 탈락·승리, 모든 타일 공개, 재시작                         |
| 7   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                              |

### 게임 메인(3번) 구성 요소

- **내 타일 줄** — 값 보임(나만), 오름차순. 새로 뽑은 타일은 삽입 위치 미리보기.
- **상대 타일 줄** — 뒷면 + 위치(몇 번째)만. 공개된 것은 앞면.
- **더미·드로우** — 남은 수 + [뽑기] 버튼(내 턴).
- **추리 패널** — 지목한 상대 타일 + 숫자 키패드(0~11)/[조커] + [선언].
- **계속/멈춤 버튼** — 정답 후 등장.

### 인게임 안내·경고·피드백 장치 (모바일 화면 기준)

- **드로우 프라이버시:** 뽑은 타일은 **내 화면에만** 크게 확대 표시(상대엔 "상대가 뽑는 중"만). 손으로 가리는 실물 감각을 UI로 대체.
- **삽입 위치 자동 안내:** 뽑은 타일을 정렬 규칙상 **들어갈 자리**를 자동 하이라이트(오배치 방지). 조커만 수동 위치 선택 허용 + "조커는 원하는 곳에 숨길 수 있어요" 안내.
- **오답 리스크 경고등:** [선언] 직전, 이번에 틀리면 **공개될 내 타일(방금 뽑은 것)**을 붉게 미리보기 + "틀리면 이 타일이 공개됩니다" 확인. 확신 없는 지름 방지.
- **가능 값 힌트(캐주얼):** 지목한 칸에 대해 공개 정보로 좁혀진 **후보 숫자만 키패드 활성**, 불가능한 수는 흐리게. 랭크전에선 전 숫자 활성(순수 계산).
- **연속 추리 안내:** 정답 시 "한 번 더? 멈추면 안전" 라벨과 함께 지금까지 손에 든 타일이 계속 리스크임을 명시.
- **정렬·색 규칙 툴팁:** 동수 배치 시 "검정<흰색" 규칙 상시 미니 범례. 헷갈리는 신규 배려.
- **타이머:** 25초 링, 10초 노랑·3초 진동. 초과 시 "자동 멈춤 — 뽑은 타일 비공개 보관" 고지.
- **탈락·승리 연출:** 마지막 타일 공개 순간 강조 + "○○ 탈락" 안내(다인전은 관전 전환). 최후 1인 시 결과.
- **네트워크:** 상대 지연 스피너, 끊김 시 재접속 대기(타일·더미는 서버 보관값 복원, 진행 중 추리는 롤백).

### 서버/로직이 처리할 것

- **타일 세트·배분기** — 시드 배분, **각자 값은 소유자에게만**(상대엔 위치·뒷면), 서버가 실제값 보관(치트 방지 핵심).
- **정렬·삽입 엔진** — 값+색 규칙 자동 정렬, 조커 수동 위치, 위치 인덱스 공개.
- **추리 판정** — 지목 값 vs 실제값(조커 포함) 비교, 정답=상대 공개/오답=자기 공개, 연속·멈춤 처리.
- **탈락·승패 관리** — 전부 공개 시 탈락, 최후 1인 판정.
- **(선택) 후보 계산기** — 공개 정보로 각 숨은 칸의 가능 값 집합 산출(캐주얼 힌트용, 순수 로직·AI 아님).

> **AI 불필요 근거:** 콘텐츠는 **고정 숫자·색 타일**. 시스템은 배분·정렬·값 비교·(선택)제약 계산만. 추론은 사람 몫. LLM 전무.

### 통신

- **턴마다: 드로우 1건(값은 본인만) + 추리 선언 1건(위치+값) + 판정 결과 브로드캐스트 1건.** 연속 추리는 반복. → 턴당 소량. 실제 타일값은 서버 보관, 공개 시점에만 노출.

## 라인업에서의 위치

- 1번 모순(연역·조건부 규칙) · 2번 냥호(귀납) · 3번 우다다(순발력) · 4번 냥탈출(협동) · 냥파장(감각) · 냥말 블러핑(정체) · 쿼리모(추상 전략) · 모디언트릭(베팅 심리) · 모루먼쇼(카드 관리)
- **신규 모빈치코드** = **정렬 제약 추리+리스크** (2~4인) ← 모순과는 완전히 다른 뇌. 모순은 주어진 조건부 규칙으로 폭탄 칸을 연역하는 논리 게임이고, 이쪽은 '정렬·색 제약 + 공개 정보 전파'로 숨은 숫자를 좁히며 **오답 시 자기 정보 손실**이라는 리스크 관리가 얹힌 확률 추리다. 겹치지 않는다. 2인 순수 두뇌전으로 특히 강함.
- 공통: 가벼운 통신(드로우/추리/판정), 타일 UI라 Canvas 불필요, HTML/CSS로 고퀄. **고정 타일 세트 · AI 불필요.**
