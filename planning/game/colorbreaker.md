# 컬러 브레이커 — 기획 정리서

> 1:1 패턴 해킹 게임. 색 버튼을 눌러 나오는 O/X만 보고, 시스템이 숨긴 규칙을 역추적한다. 전광판의 모든 반전은 랜덤이 아니라 **규칙으로 설명 가능**하다.

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 색 버튼을 눌러 O/X를 확인하며, 숨겨진 **마스터 룰**을 먼저 완전히 맞히면 승리.

### 화면 구성

- **색 버튼 5개** (빨·파·노·초·보) — 내가 누르는 입력
- **공용 전광판** — 양쪽이 누른 색과 O/X 판정이 순서대로 기록됨 (둘 다 봄)

### 내 턴에 할 수 있는 것 (둘 중 하나)

1. **실험** — 색 하나 눌러 O/X 확인 (정보 얻기)
2. **선언** — 마스터 룰의 정체 맞히기 → 맞으면 승리, 틀리면 **몇 턴 정지**

### 마스터 룰은 2층

- **1층 (기본 패턴)** — 예: "따뜻한 색 뒤 차가운 색이면 O"
- **2층 (반전 규칙)** — 예: "단, 보라 직후의 판정은 반전된다"
- 전광판에 "어? 이건 1층과 안 맞는데?" 싶은 이상치가 뜨면, 그건 **2층이 걸린 것**. 랜덤 아님.

### 핵심 감각

- 전광판은 공용 → 상대 실험도 내 데이터가 된다 (같이 쌓아야 규칙이 보임).
- 하지만 먼저 맞히는 한 명이 이긴다 → 협동하며 눈치 보는 싸움.
- 1층만 맞히면 소점, 2층까지 맞히면 대점 → 상대가 1층 먼저 대도 역전 가능.

---

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 각 플레이어 화면에 5색 버튼. 공용 전광판 1개.
- 매 판 시작 시, 시스템이 **숨겨진 마스터 룰(1층 + 2층)**을 무작위로 지정. 양쪽 모두 모름.
- 인원: **2인 고정.**

### 마스터 룰 = 2층 구조

- **1층 (기본 패턴):** 입력 시퀀스에 대한 상시 판정 규칙.
- **2층 (반전 규칙):** 특정 트리거가 걸리면 그 판정을 뒤집거나 바꾸는 예외.
- 전광판의 모든 이상치는 2층으로 설명 가능해야 한다(인과 성립). **순수 랜덤 판정은 없음.**

### 턴 진행 (2인 교대)

자기 턴에 아래 2택 1.

**① 실험** — 색 버튼 1개 입력

- 전광판에 [누른 색] + [O/X 판정] 기록.
- 판정은 1층·2층 규칙에 따라 결정됨.

**② 선언** — 마스터 룰을 말함

- 완전 정답(1+2층) → 즉시 승리 (대점).
- 1층만 정답 → 부분 인정 (소점) — _아래 승리 조건 참고._
- 오답 → **N턴 정지** (기본값 아래 확정 필요).

### 판정 기준 (확정)

- O/X는 **직전 입력 1개와 방금 입력의 관계**로 판정 (전체 시퀀스가 아님).
  - 첫 입력은 비교 대상이 없으므로 판정 없음(-) 또는 항상 O 중 하나로 고정 → **판정 없음(-)** 으로 처리.
- 2층 트리거도 최근 입력 흐름에서 판정 (관측 가능하도록).

### 2층 관측 보장 (중요)

- 2층이 너무 드물게 발동하면 영영 못 찾음 → **2층 트리거는 "판당 최소 1회 이상 반드시 발동"**하도록 룰 생성 시 보장.
- 트리거 색/조건은 플레이어가 실험으로 유도할 수 있어야 함 (특정 색 누르면 재현 가능).

### 협동 / 경쟁 구조

- **협동:** 전광판이 공용 → 내 실험이 상대 데이터가 되고, 상대 실험이 내 데이터가 됨. 같이 쌓아야 규칙이 드러남.
- **경쟁:** 최종 선언 점수는 개인. 상대가 1층 먼저 선언해도 나는 2층까지 크랙해 역전 가능.

### 승리 조건 (점수제)

- **2층까지 완전 정답 선언 = 즉시 승리.**
- 1층만 맞힌 선언은 부분 점수 → 그 판은 계속 진행, 2층 크랙한 쪽이 최종 승. (1층 정답이 상대에게 힌트를 주는 리스크도 됨)
- 빨리 맞힐수록 고득점 / 시간 지날수록 배점 하락 (선착 독식 방지, 늦어도 부분 점수).

### 힌트 경제 (선택 요소)

- O를 띄우면 **힌트 토큰** 획득 → "룰은 색 온도와 관련" "반전 트리거는 특정 색" 같은 힌트 1줄과 교환.
- 자원을 쓸지 아낄지의 전략 층 추가.

### 라운드 순환

- 누군가 2층까지 정확히 선언 → 판 종료 → 새 마스터 룰로 다음 판.

## C. 마스터 룰은 어떻게 만드나 (1번과 동일한 파이프라인)

문구를 손으로 쓰지 않고 **템플릿 뱅크 → 조합 → 검증**.

### 1층 (기본 패턴) 템플릿 뱅크

- **인접 관계:** "직전과 같은 색이면 O" / "직전과 다른 색이면 O"
- **색 온도:** "따뜻한 색(빨·노) 뒤 차가운 색(파·초)이면 O"
- **금지:** "`{색}`은 무슨 일이 있어도 O가 안 됨"
- **순번:** "홀수 번째 입력은 `{색}`일 때만 O"

### 2층 (반전 규칙) 템플릿 뱅크

- **직후 반전:** "`{색}` 직후의 판정은 반전된다"
- **주기 반전:** "매 `{N}`번째 입력마다 판정이 반전된다"
- **연속 반전:** "같은 색 2연속 뒤부터 판정이 반전된다"

### 조합 + 검증

1. 1층 1개 + 2층 1개를 무작위로 뽑아 슬롯(`{색}`, `{N}`) 채움.
2. **검증기:** 무작위 입력 시퀀스를 다수 시뮬레이션 →
   - 2층 트리거가 **합리적 횟수 내에 발동 가능한지** (관측성 보장)
   - 1층만으로는 설명 안 되는 이상치가 실제로 생기는지 (2층이 의미 있는지)
   - 두 규칙이 서로 상쇄돼 무의미해지지 않는지
3. 통과한 세트만 사용.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면                 | 핵심 요소                                       |
| --- | -------------------- | ----------------------------------------------- |
| 1   | **로비 / 매칭**      | 1:1 매칭, 방 생성·입장                          |
| 2   | **게임 메인**        | 색 버튼 5개 + 공용 전광판 + 액션                |
| 3   | **전광판**           | [색 → O/X] 시퀀스 실시간 로그 (스크롤/타임라인) |
| 4   | **선언 입력**        | 1층·2층을 고르거나 서술해 제출, 재확인          |
| 5   | **정지 상태**        | 오답 후 N턴 대기 표시                           |
| 6   | **힌트 상점** (선택) | 토큰으로 힌트 교환                              |
| 7   | **결과 (승/패)**     | 마스터 룰 정답 공개, 점수, 재시작               |
| 8   | **가이드/규칙**      | 위 A 섹션 (인게임 상시 열람)                    |

### 게임 메인(2번) 구성 요소

- **색 버튼 5개** — 내 입력 (내 턴에만 활성)
- **공용 전광판** — 양쪽 입력·판정 순서대로. 이상치(2층 발동 의심) 구간 시각 강조 고려
- **턴 표시** — 내 턴 / 상대 턴
- **내 힌트 토큰** — 보유 수 (선택 요소)
- **액션** — 실험(색 누르기) / 선언(룰 맞히기) / 힌트 교환(선택)

### 서버/로직이 처리할 것

- **마스터 룰 생성기** — 1층·2층 템플릿 조합 + 슬롯 채우기
- **룰 검증기** — 2층 관측성·유의미성·비상쇄 시뮬레이션 (핵심)
- **판정 엔진** — 입력 시퀀스에 1층·2층 적용해 O/X 산출
- **선언 채점** — 1층/2층 정답 여부 판정, 부분 점수 계산
- **턴/상태 관리** — 턴 교대, 정지 카운트, 승패, 라운드 순환

## E. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

아래는 감이 아니라 "왜 이 값인지" 근거를 붙인 시작값. 실제 플레이 데이터로 ±조정.

1. **오답 선언 정지** → **2턴 정지.**
   - 1턴은 너무 가벼워 막 지르게 되고, 3턴+는 한 번 실수로 판이 기울어 과함. 2턴이면 "확신 없으면 못 지르지만, 틀려도 복구 가능한" 밸런스.
2. **점수 배점** → **1층만 = 1점 / 2층까지 = 3점.**
   - 2층이 1층보다 훨씬 어려우므로 3배. 1층만 먼저 선언해 1점 챙겨도, 2층 크랙한 상대가 3점으로 뒤집을 수 있어 끝까지 긴장 유지.
3. **시간 감쇠** → 판 시작 후 **매 4턴마다 완전정답 배점 -0.5점(최저 1.5점까지)**.
   - 빨리 풀수록 이득이되, 늦게 풀어도 최소 1.5점은 보장 → 선착 독식 완화.
4. **힌트 경제** → **채택.** O 3개당 토큰 1개, 토큰 1개로 힌트 1줄.
   - "지금 O 띄우려고 뻔한 색 누를까 vs 정보 되는 색 누를까"의 미니 딜레마 추가.
5. **2층 난이도 곡선** → 첫 판은 **직후 반전형(가장 관측 쉬움)**만. 판이 진행될수록 주기·연속 반전형 해금.
   - 첫 판부터 어려운 2층이 나오면 진입장벽이 큼. 쉬운 것부터 학습시키는 곡선.
6. **매치 승리 조건** → **먼저 5점** 도달 시 매치 승 (여러 판 누적).
   - 단판 운(쉬운 룰 뽑기)의 영향을 줄이고 실력이 수렴하도록.

> 3·5는 특히 실측 의존 — 시뮬레이션으로 "판당 평균 몇 번 실험해야 2층이 관측되는지" 재서 감쇠 주기와 해금 순서를 맞추면 정확하다.
