# 냥호 브레이커 (가칭) — 기획 정리서

> 1:1 추론 대전. 숨겨진 **암호 조합**을 추측하고, "몇 개 맞았는지"라는 풍부한 피드백을 모아 먼저 정답을 알아낸다. 확신이 서면 지르되, 틀리면 그 판을 잃는다.

_가칭 후보: 냥호 브레이커 / 캣 크래커 / 발바닥 코드_
_(2번 슬롯 「컬러 브레이커」를 대체 — 색+O/X의 겹침·건조함 문제를 해결한 재설계본)_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 숨겨진 **기호 조합**을 추리로 먼저 알아내면 승리!

### 정답이란

- 정해진 칸 수(기본 4칸)에 **고양이 기호**가 순서대로 숨겨져 있음.
- 예: 🐟 🧶 🐾 🔔 (내겐 안 보임)

### 내가 하는 것

1. **추측** — 내가 생각한 조합을 제출.
2. **피드백** — 시스템이 알려줌:
   - 🟢 **정확** = 기호도 자리도 맞은 개수
   - 🟡 **자리만 틀림** = 기호는 있는데 위치가 틀린 개수
3. 이 피드백을 모아 **정답을 좁혀감.**

### 승리

- **정답 선언** → 맞으면 **즉시 승리**, 틀리면 **그 판 패배.** (확신 서면 지르기)
- 상대와 **같은 암호**를 각자 풀어서, **먼저 맞히는 사람이 승리.**

### 찬스

- **훔쳐보기 1회** — 게임 중 한 번, 상대의 추측 한 줄을 엿볼 수 있음. (쓸지 아낄지 선택)

---

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 숨겨진 **암호 = 기호 N칸의 순서 조합**. 기호는 고양이 테마 세트(🐟생선·🧶실뭉치·🐭쥐·🐾발바닥·🔔방울·⭐별 등)에서.
- 두 플레이어는 **같은 암호**를 각자 자기 화면에서 품(같은 시드 → 공정).
- 인원: **2인 대전.**

### 진행 (실시간 동시)

- 두 사람이 **동시에 각자 추론.** 턴 교대가 아니라 각자 페이스로 진행 → 항상 자기 보드에 바쁨(관전 없음).
- 자기 화면에서 반복:
  1. **추측 제출** → 즉시 피드백(🟢정확 수 / 🟡자리만 틀림 수). **피드백은 나만 봄.**
  2. 추측 기록이 아래로 쌓임 → 시각적으로 정보가 축적됨.
- 언제든 **정답 선언** 가능:
  - 정확히 맞음 → **즉시 승리.**
  - 틀림 → **그 판 패배.** (1번 모순의 "폭탄 찾기"와 동일한 리스크 구조)

### 피드백 규칙 (마스터마인드 표준)

- 🟢 정확: 기호 O + 위치 O.
- 🟡 자리만: 기호 O + 위치 X. (중복 기호 계산은 표준 방식 — 정답에 있는 개수만큼만 카운트)
- 나머지는 표시 안 함(=오답). → 한 번의 추측이 위치·개수 정보를 동시에 주므로 O/X보다 정보량이 훨씬 큼.

### 대전 상호작용 (워들에 없는 우리만의 차별점)

"각자 조용히 푸는 병렬 숫자야구"가 아니라, **서로 얽히는 실시간 대전**으로 만드는 3요소:

**① 공유 진행 바 (긴장 가시화)**

- 상대의 **추측 횟수 / 최고 정확도(🟢 몇 개까지 갔는지)**가 내 화면에 실시간 표시됨. 내용(어떤 추측)은 비공개.
- "상대가 벌써 🟢3개까지 갔다 → 곧 풀겠는데? 나도 슬슬 질러야 하나?" → **선언 타이밍 압박.** 1번(모순)의 "언제 폭탄 찾기 지를까"와 같은 긴장.

**② 훔쳐보기 (정보 · 리스크)**

- 게임당 **1회**, 상대의 추측 기록 한 줄(추측+피드백)을 엿봄. 같은 암호라 상대 시도가 내 단서도 됨.
- 단, 쓰면 상대에게 **"엿봤다" 표시** + 그 대가로 상대는 **훔쳐보기 1회를 새로 얻음**(리스크·견제).

**③ 교란 카드 (한 번의 방해)**

- 게임당 **1회**, 상대에게 **가짜 피드백 한 줄**을 심음(다음 상대 추측의 🟢🟡가 한 번 틀리게 표시). 단 상대도 "교란당함" 경고를 받아 그 줄을 의심하게 됨.
- "정보를 흔들어 시간을 뺏는" 심리 무기. 1회뿐이라 언제 쓸지가 핵심.

> 이 3요소로 "같은 암호를 각자 푸는데, 상대 상태가 보이고, 정보를 훔치거나 흔들 수 있는" 실시간 심리 대전이 됨. 워들(혼자·비실시간)이 못 주는 자극.

### 워들식 매력 포인트 이식 (검증된 포장)

- **같은 암호 공유:** 둘이 완전히 같은 문제를 품 → "나는 4번에 풀었는데 너는?" 하는 직접 비교의 쾌감.
- **결과 공유:** 판 종료 후 추측 여정을 🟢🟡 이모지 격자로 요약 → 스포 없이 자랑/공유(워들의 바이럴 장치).
- **데일리 챌린지(선택):** 매일 하나의 공통 암호를 전 유저가 도전하는 비대전 모드 → 순위·연속기록(streak)으로 재방문 유도.

### 왜 이 방식이 컬러 브레이커의 문제를 푸는가

- **겹침 없음:** 정답이 유일한 조합 → 피드백이 결정적으로 정답 하나로 수렴. (색+규칙 방식의 "여러 규칙이 같은 패턴" 문제 원천 제거)
- **건조함 해결:** 추측→피드백의 손맛, 아래로 쌓이는 기록의 진행감, 좁혀지는 게 눈에 보임.
- **1번과 안 겹침:** 모순=주어진 조건부 단서의 **연역**, 냥호=내 추측 피드백을 모으는 **귀납.** 두 두뇌 게임이 다른 사고를 씀.

### 라운드 / 매치

- 한 판 = 암호 하나 크랙. 승패는 정답 선언(승) 또는 오답 선언(패)으로 확정.
- **매치 = 3판 2선승.** 판마다 새 암호(새 시드).

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **암호 길이 / 기호 수 / 중복** → 난이도 모드로:
   - **쉬움:** 4칸 / 6기호 / **중복 없음**
   - **보통:** 4칸 / 6기호 / **중복 허용** (기본)
   - **어려움:** 5칸 / 7기호 / 중복 허용
   - (중복 허용이 훨씬 어렵고 깊음 — 자리 피드백 해석이 까다로워짐)
2. **훔쳐보기** → 게임당 **1회.** 사용 시 상대에게 노출 + 상대는 훔쳐보기 1회 획득.
3. **교란 카드** → 게임당 **1회.** 상대 다음 추측 1줄의 피드백을 왜곡. 상대는 "교란됨" 경고 받음.
4. **공유 진행 바** → 상대의 추측 횟수 + 최고 🟢 개수만 표시(내용 비공개).
5. **오답 선언 페널티** → **그 판 즉시 패배**(폭탄 구조). 확신 없이는 못 지르게.
6. **소프트 타이머(선택)** → 판당 **3분** 소프트 리밋. 초과 시 "지금까지 정보로 강제 선언" 또는 무승부 처리. (한없이 늘어지는 것 방지)
7. **매치** → 3판 2선승.
8. **첫 추측 힌트(초보 배려, 선택)** → 쉬움 모드 한정, 시작 시 🟢 하나가 어느 칸인지 살짝 귀띔.

> 1·3은 밸런스 핵심 — "평균 몇 번 추측에 풀리는지"를 실측해 길이/기호 수와 소프트 타이머를 맞추면 정확하다.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면               | 핵심 요소                                  |
| --- | ------------------ | ------------------------------------------ |
| 1   | **로비 / 매칭**    | 2인 매칭, **난이도 선택**                  |
| 2   | **대기 / 준비**    | 같은 시드 수신, 규칙 표시                  |
| 3   | **게임 메인**      | 기호 입력 + 추측 기록판 + 피드백 + 액션    |
| 4   | **정답 선언 확인** | 조합 확정 → "정말?" 재확인(돌이킬 수 없음) |
| 5   | **훔쳐보기 뷰**    | 상대 추측 한 줄 표시                       |
| 6   | **결과**           | 승/패, 정답 공개, 추측 횟수, 재시작        |
| 7   | **가이드/규칙**    | 위 A 섹션 (인게임 상시 열람)               |

### 게임 메인(3번) 구성 요소

- **기호 팔레트** — 고양이 기호 버튼(선택해 칸 채우기)
- **현재 추측 입력줄** — N칸에 기호 배치 후 제출
- **추측 기록판** — 지난 추측들 + 각 줄의 🟢🟡 피드백이 아래로 누적
- **액션** — 추측 제출 / 정답 선언 / 훔쳐보기(1회)
- **상대 상태 표시** — 상대 추측 횟수, 훔쳐보기 사용 여부(내용은 비공개)

### 서버/로직이 처리할 것

- **암호 생성기** — 시드 기반, 난이도값(길이·기호수·중복)대로. 양쪽 같은 암호.
- **피드백 계산기** — 추측 대비 🟢🟡 산출(중복 표준 처리). if/카운팅 수준, 가벼움.
- **선언 판정** — 정답 일치 여부 → 승/패.
- **훔쳐보기 중계** — 상대의 특정 추측 줄 1개 전달 + 노출 플래그.
- **매치 관리** — 판수, 새 시드, 승패 집계.

### 통신

- 시작(같은 시드 수신) + 종료(승패) + 훔쳐보기 요청 시 1줄. → 매우 가벼움. 실시간 위치·물리 동기화 없음.
