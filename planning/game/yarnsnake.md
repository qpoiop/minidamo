# 실뭉치 스네이크 (가칭) — 기획 정리서

> 2~4인 턴제 영역 대전. 격자 위에서 각자 실뭉치 꼬리를 늘려 자기 색 길을 남긴다. 벽·꼬리에 부딪히면 탈락. 모두가 **동시에** 다음 칸을 예약하고 한꺼번에 공개 — 상대의 수를 읽고 길을 막는 심리·계산 싸움. 실시간 반응이 아니라 **한 수 한 수 생각하는** 트론.

_가칭 후보: 실뭉치 스네이크 / 냥트론 / 실꼬리 대전_
_(우다다 대시가 '순발력'이라면, 이건 같은 격자 소재를 '계산·수읽기'로 뒤집은 전략판)_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 실꼬리를 늘려 상대 길을 막아라. 부딪히면 탈락, **마지막까지 살거나 땅을 더 차지**하면 승리.

### 화면

- 격자 보드 **전체가 보임**(숨김 없음). 각자 자기 색 고양이가 있고, 지나온 칸엔 **실 자국**이 남는다.
- 실 자국과 벽은 **다시 못 지나감**(자기 것도 포함).

### 조작

- 매 턴 **다음으로 갈 방향(상하좌우) 1칸을 예약**한다.
- 전원이 예약을 끝내면 **동시에 한 칸씩 전진**하고 결과가 공개된다. (반응속도 아님 — 생각할 시간 있음)

### 부딪히면(탈락)

- 예약한 칸이 **벽 / 실 자국 / 보드 밖**이면 그 자리서 **탈락.**
- 두 고양이가 **같은 칸을 동시에** 노리면 → **둘 다 탈락**(정면 충돌).

### 승리

- **생존 승:** 마지막까지 안 부딪힌 사람이 승리.
- **영역 승(무승부 대비):** 전원 동시 탈락 등으로 생존자가 안 갈리면 → **자기 실 자국(차지한 칸)이 많은 쪽 승.**

### 실뭉치 아이템 (보드에 등장)

| 아이템 | 효과 |
| --- | --- |
| 🧶 실뭉치 | 다음 턴 **2칸 전진**(가속 한 수) |
| ✂️ 가위 | 내 **바로 앞 벽 1칸을 뚫고** 지나감(탈출용, 1회) |
| ⭐ 별 | 차지 칸 **+3 보너스**(영역 승 대비 점수) |

- 아이템은 **양쪽 모두 같은 위치**에 스폰(같은 시드 → 공정).

### 핵심 감각

- 넓은 곳을 선점하고 상대를 **좁은 구석으로 몰아** 스스로 갇히게 만든다.
- 동시 공개라 "상대가 여기로 올 것"을 예측해 길목을 먼저 막는다.
- 내 꼬리도 벽이 된다 — **자기 무덤을 파지 않게** 퇴로를 남긴다.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2~4인.** 격자 보드(크기는 인원·모드별, C 참고).
- 각자 시작 위치·시작 방향은 **시드 기반으로 대칭 배치**(공정성). 예: 4인이면 네 모서리 부근.
- 보드 외곽은 벽. 내부에 랜덤 장애 벽 약간(시드 동일).

### 턴 진행 (동시 예약 → 동시 해석)

1. **예약 단계:** 살아있는 전원이 각자 다음 방향(상하좌우 중 1)을 비공개로 선택. 제한시간 있음.
2. **해석 단계:** 전원 예약이 끝나면(또는 시간 종료) **동시에** 한 칸씩 이동 처리.
3. **충돌 판정(동시 적용):**
   - 목적 칸이 벽/기존 실 자국/보드 밖 → 그 플레이어 탈락.
   - 서로 다른 두 명 이상이 **같은 목적 칸** → 해당 전원 탈락(정면/교차 충돌).
   - 두 명이 서로의 **직전 칸을 맞바꾸는**(스왑) 이동 → 둘 다 탈락(스치며 충돌로 간주).
4. **자국 갱신:** 생존자가 지나온 칸에 자기 색 실 자국을 남김(이후 통과 불가).
5. 다음 턴 반복.

- **반응속도 무관:** 예약 제한시간 내라면 언제 확정하든 결과 동일(동시 해석). 순발력이 아니라 **판단**이 승부.

### 이동·통과 규칙

- 한 턴 1칸 이동(아이템으로 예외). 제자리·역방향(바로 뒤 칸) 선택 불가(자기 꼬리라 즉사).
- 예약 시간 내 **미입력** → 직전 진행 방향으로 **자동 직진**(방치 시 벽으로 돌진해 자멸 가능).

### 아이템

- 🧶 **실뭉치** — 획득 후 다음 턴 2칸 전진(중간 칸도 자국 남김, 중간 칸이 막혀 있으면 그 지점서 탈락).
- ✂️ **가위** — 보유 시 1회, 예약과 함께 사용하면 앞 벽/실 자국 1칸을 무시하고 통과(그 칸은 뚫린 것으로 처리). 상대 실 자국도 뚫을 수 있어 **역전 수**.
- ⭐ **별** — 즉시 획득, 영역 점수 +3(생존 승엔 무관, 무승부/영역 승 대비).
- 스폰: 일정 턴마다 빈 칸에 시드 기반 등장(양쪽 동일 위치).

### 종료 & 승패

- **생존자 1명 남으면** 즉시 종료 → 그 사람 승리.
- **같은 턴에 마지막 생존자들이 동시 탈락** → **영역 점수(자기 실 자국 칸 수 + 별 보너스)** 비교, 많은 쪽 승.
- **영역까지 완전 동점** → 무승부(재경기).
- 보드가 꽉 차 아무도 못 움직이는 교착도 영역 점수로 판정.

### 왜 머리를 쓰는가 (설계 의도)

- **공간 계산:** 남은 열린 칸을 세어 누가 더 넓은 구역을 확보했는지 판단(트론의 'space control').
- **수읽기:** 동시 공개라 상대 다음 칸을 예측해 길목을 선점하거나 정면충돌을 유도/회피.
- **자기 관리:** 자기 꼬리가 곧 함정 — 퇴로를 남기며 상대를 가둔다. 반응이 아닌 계획의 게임.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **보드 크기** → 인원별: **2인 13×13 / 3인 15×15 / 4인 17×17.** 인원 늘수록 넓혀 초반 즉사 방지.
2. **시작 배치** → 대칭(2인 좌우, 3인 삼각, 4인 사각 모서리). 시작 방향은 보드 중앙을 향하게.
3. **예약 제한시간** → **턴당 8초.** 생각할 시간은 주되 늘어짐 방지. 미입력 시 자동 직진.
4. **내부 랜덤 벽** → 전체 칸의 약 **8%.** 너무 많으면 초반 사고多, 적으면 단조. 대칭 배치.
5. **아이템 스폰 주기** → 평균 **6턴마다 1개.** 실뭉치:가위:별 = **5:2:3**.
6. **가위 보유 상한** → 1개(중복 획득 시 미획득 처리). 남발 방지.
7. **매치** → **3판 2선승.** 판마다 새 시드(배치·벽·아이템 위치 변경).
8. **동점 처리** → 생존 우선 → 영역 점수 → 완전 동일 시 무승부(재경기).

> 1·3·4는 실측 핵심 — "평균 몇 턴에 첫 탈락이 나오는지 / 교착이 자주 생기는지" 재서 보드 크기·벽 밀도·제한시간을 맞춘다.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                             |
| --- | --------------- | ---------------------------------------------------- |
| 1   | **로비 / 매칭** | 2~4인 매칭, 방 생성, 인원·보드 크기 표시              |
| 2   | **대기 / 준비** | 시드·인원·규칙 표시, 준비 완료                        |
| 3   | **게임 메인**   | 전체 격자 + 각 색 꼬리 + 방향 예약 컨트롤 + 턴 타이머 |
| 4   | **해석 연출**   | 동시 전진 애니 + 충돌·탈락 강조                       |
| 5   | **영역 표시(선택)** | 실시간 차지 칸 수 게이지                          |
| 6   | **결과**        | 생존/영역 승패, 최종 보드(색 분포), 판수 스코어, 재시작 |
| 7   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                          |

### 게임 메인(3번) 구성 요소

- **전체 격자 보드** — 벽·아이템·각 플레이어 색 실 자국·현재 머리 위치 표시.
- **방향 예약 컨트롤** — 상하좌우 D-pad(냥탈출과 동일 컴포넌트 재사용 가능). 선택 후 "확정" 또는 재선택.
- **예약 상태 인디케이터** — 누가 예약을 마쳤는지(내용 비공개, 완료 여부만).
- **턴 타이머** — 8초 카운트다운.
- **아이템 보유 표시** — 가위 등 보유 아이템.
- **영역 게이지(선택)** — 각 색이 차지한 칸 수.

### 서버/로직이 처리할 것

- **보드 생성기** — 시드 기반 격자 + 대칭 시작 배치 + 내부 벽 + 아이템 위치. 전원 동일.
- **동시 턴 해석기(핵심)** — 전원 예약 수집 → 동시 이동 → 충돌 규칙(벽/자국/같은칸/스왑) 일괄 판정 → 자국 갱신. if/격자 수준, 가벼움.
- **아이템 효과** — 실뭉치(2칸)·가위(벽 뚫기)·별(점수) 적용.
- **영역 계산** — 각 색 자국 칸 수 + 별 보너스(무승부/영역 승 대비).
- **승패·매치 관리** — 생존/영역 판정, 판수, 새 시드.

### 통신

- **턴마다 각자 예약 방향 1건**(상/하/좌/우 + 가위 사용 플래그) 전송 → 전원 도착 시 결과 브로드캐스트 1건. → 턴당 초경량 메시지. 실시간 프레임 동기화 불필요(동시 턴 방식이라 순번만 맞으면 됨).

## 라인업에서의 위치

- **1번 코드네임: 모순** = 연역 추리 (대전)
- **2번 냥호 브레이커** = 귀납 추리 (대전)
- **3번 우다다 대시** = 순발력·조작 (대전)
- **4번 냥탈출** = 협동·소통 (협동)
- **신규 실뭉치 스네이크** = **공간 전략·수읽기** (2~4인) ← 우다다 대시와 같은 '격자·실뭉치' 소재를 반응속도가 아닌 **턴제 계산**으로 뒤집은 대전. 추리(정보)와도, 순발력(조작)과도 다른 '판을 읽는' 뇌.
- 공통: 가벼운 통신(방향 예약 1건/턴), 격자 + if문 판정이라 실시간 물리 불필요, HTML/CSS(+격자 렌더)로 구현 가능.
