# 냥말 블러핑 (가칭) — 기획 정리서

> 2~4인 정체 추리 대전. 모두가 같은 **단어 보드**를 본다(전부 앞면). 게임 시작 시 각자 보드의 카드 한 장을 **자기 카드**로 랜덤 배정받는데, **그게 뭔지는 본인만** 안다. 매 턴 자기 카드에 맞는 **표현 한 마디**를 내야 하고 — 그게 곧 자기 정체를 흘리는 일. 보드의 절반은 뜻이 겹치는 **유사군**이라 단서 하나로는 안 들킨다. 남들의 자기-단서를 읽어 **나머지 전원의 카드를 알아맞히면 승리**, 하나라도 틀리면 그 자리서 **탈락**. 흘리기와 읽기, 그리고 언제 확신하고 지를지의 싸움.

_가칭 후보: 냥말 블러핑 / 숨은말 냥 / 정체냥_
_(연역·귀납 추리가 '주어진 단서를 논리로 좁히는' 게임이라면, 이건 '내 정체는 숨기며 남의 정체를 캐는' 정보 비대칭 추리. 생선 도둑이 순수 블러핑이라면 이건 공유보드 위 눈치·추리)_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 보드의 카드 한 장이 **내 정체**(나만 앎). 매 턴 내 카드 표현을 흘리며, 남들의 카드를 역으로 캔다. **나머지 전원을 맞히면 승리**, 틀리면 **탈락**.

### 화면

- **공유 단어 보드**(4×4 또는 5×5, 방 옵션)를 전원이 함께 본다. 시작 시 **전 카드가 앞면**으로 공개 — 단어는 다 보인다.
- 그 중 **내 카드 1장만 나에게 하이라이트**(별도 표기로 계속 인지). 남의 카드는 안 보임.

### 내 턴에 하는 것 (둘 중 하나)

1. **단서 흘리기** — 내 카드에 맞는 **표현 한 마디**를 낸다. 참이어야 하고, **매번 새로운 속성**으로(반복 금지). 유사군 덕에 여러 카드에 걸쳐 안 들킴.
2. **전원 지목** — 나 말고 **남은 참가자 전원의 카드**를 한 번에 지목한다.
   - **전부 정답** → 즉시 **승리**.
   - **하나라도 틀림** → 즉시 **탈락**. 내 카드가 공개되고 "○○ 탈락" 안내가 전원에게 뜬다.

### 탈락 & 승리

- 탈락자는 **관전**(여러 명 남았을 때). 남은 사람이 **한 명뿐이면 그 사람 승**(결과 표시).
- 즉, 이기는 길은 둘: **내가 전원을 정확히 맞히거나 / 남들이 자멸해 마지막에 남거나.**

### 핵심 감각

- 내 단서는 나를 흘린다 → 유사군 뒤에 **최대한 애매하게** 숨기되, 참은 지켜야.
- 남의 단서가 쌓일수록 그의 카드가 좁혀진다 → **언제 확신하고 지를지.**
- 지목은 전원 올바를 때만 승, 틀리면 자멸 → 성급하면 죽고 늦으면 남이 먼저 맞힌다.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2~4인.**
- 보드: **4×4(16장)** 또는 **5×5(25장)**, 방에서 선택(인원 많거나 어렵게 하려면 5×5).
- 시드 기반으로 보드 단어·각자 배정 카드를 결정(공정성·재접속).
- 보드 구성 = **유사군 카드(뜻범위 겹침) + 분산 카드** 혼합. **각자의 배정 카드는 유사군 안에서** 뽑는 걸 기본으로(그래야 단서가 겹쳐 안 들킴). 배정 안 된 나머지는 전부 **미끼 카드**.
- 시작 시 전 카드 앞면 공개, 내 카드만 나에게 하이라이트.

### 턴 진행 (순번 교대)

1. 자기 차례에 **행동 택1:**
   - **(a) 단서 흘리기** — 내 카드에 대한 표현 한 마디 입력. 아래 단서 규칙 준수.
   - **(b) 전원 지목** — 남은 상대 전원의 카드를 각각 지정.
2. **(b) 판정:**
   - 지목이 **모두 정답** → 지목자 **즉시 승리**, 게임 종료.
   - **하나라도 오답** → 지목자 **즉시 탈락**, 그의 카드 공개 + 전원 알림. 남은 인원으로 계속.
3. 다음 사람 차례. 남은 사람이 1명이면 그 사람 승.

- **강제 행동:** 패스 없음. 지목할 확신이 없으면 (a) 단서를 내야 하므로 매 턴 정보가 조금씩 샌다 = 게임의 엔진.

### 단서 규칙 (반칙 방지 · 자율 + 명시 금칙)

- **참일 것:** 내 카드에 실제로 해당하는 속성만(거짓 단서 금지 → 추리의 기준점 보존).
- **새 속성일 것:** 내가 이전에 낸 단서를 반복·재탕 금지 → 매 턴 정보가 쌓여 결국 좁혀짐(무한 뭉개기 방지).
- **직접 노출 금지:** 내 카드 단어 자체·직역·자명한 동의어, 보드의 다른 카드 이름 직접 언급, 보드 좌표("2행 3열") 금지.
- 시스템은 의미 검증을 못 하므로(AI 없음) **코드네임처럼 자율 준수 + 신고.** 위반 신고 시 해당 단서 무효/재입력.

### 왜 유사군이 절반이어야 하나 (핵심 설계)

- 유사군이 없으면 첫 단서가 카드를 콕 집어 → 한 턴 만에 정체가 드러남.
- 절반이 유사군이면 "바다"라는 단서가 참치·연어·고등어 **3장에 동시에 걸려** 안 좁혀짐 → 안전하게 흘리며 남을 관찰할 시간이 생김.
- 그래서 정체는 **여러 단서의 교집합**으로만 드러남. 상대의 교집합을 먼저 완성하는 쪽이 지목하고, 자기 교집합은 늦게 완성되게 조절 → 흘리기·읽기·타이밍의 삼중 줄타기.

### 정보 공개 범위

- **공개:** 전체 보드 단어, 각자 낸 단서 로그, 탈락 시 그 사람 카드, 승패.
- **비공개:** 각자의 배정 카드(본인만), 생존자들의 정체(지목·탈락 전까지).

### 왜 머리를 쓰는가 (설계 의도)

- **정보 비대칭 관리:** 이기려면 남을 다 읽어야 하는데, 그 정보는 남이 흘려줘야 나온다 → 서로 흘리기를 미루는 눈치 싸움.
- **확신 곡선:** 지목은 전원 정답이어야 승, 오답이면 자멸 → "충분히 확신했나"의 리스크 판단. 성급/지연 둘 다 벌.
- **자기 은폐:** 유사군에 숨어 참 단서를 애매하게 → 남이 나를 좁히기 전에 내가 남을 좁힌다.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **보드 크기** → 기본 **4×4(16장)**, 방 옵션 **5×5(25장)**. 큰 보드일수록 미끼가 많아 추리 난이도↑, 은폐 쉬움.
2. **유사군 비율** → 보드의 약 **절반이 유사군**(같은 뜻범위 묶음 2~3개), 나머지 분산·미끼. **배정 카드는 유사군 안에서** 추출(단서 겹침 보장).
3. **배정** → 인원수만큼 보드 카드를 랜덤 배정(중복 없음). 나머지는 미끼.
4. **단서 제한시간** → 1인당 **20초**. 초과 시 자동 패스(단서 없이 턴 종료 = 의심 유발, 남은 사람에 유리).
5. **지목 난이도 조절** → 기본은 **"남은 전원 한 번에"**. 판이 늘어지면 방 옵션 **"1명씩 지목"**(맞히면 그 대상만 탈락, 틀리면 지목자 탈락) 변형으로 완화 가능. ← 2·5는 실측 후 택.
6. **매치** → 기본 **단판제**(한 판이 완결형). 여러 판 누적 승점 리그는 방 옵션.
7. **2인 규칙** → 상대 카드 1장만 맞히면 됨 → 순수 읽기 듀얼. 서로 매 턴 단서를 흘리다 먼저 확신한 쪽이 지름(오답 시 즉패).
8. **동점 처리** → 최후 1인 생존이 명확해 무승부 거의 없음. 동시 상황은 순차 처리(지목·탈락은 1턴 1건).

> 2·5는 밸런스 핵심 — "유사군을 몇 장 섞어야 정체가 몇 턴 뒤에 겨우 드러나는지 / 전원 지목이 너무 가혹한지" 재서 유사군 비율·지목 방식을 맞춘다.

### 유사군 클러스터 사전 (예시 · 재사용 뱅크)

시스템은 아래처럼 **뜻범위가 겹치는 단어 묶음**을 들고 있다가, 유사군 클러스터 2~3개에서 여러 장 + 분산 미끼 몇 장을 뽑아 보드를 구성한다. (짧은 리스트 → 조합으로 대량 생성, AI 불필요·재사용형)

| 클러스터 | 겹치는 단어들(유사군) |
| --- | --- |
| 바다생물 | 참치 · 연어 · 고등어 · 문어 · 새우 · 조개 |
| 단맛 | 초콜릿 · 사탕 · 꿀 · 아이스크림 · 케이크 · 마카롱 |
| 빨간 것 | 사과 · 딸기 · 토마토 · 고추 · 장미 · 소방차 |
| 차가운 것 | 얼음 · 눈 · 냉장고 · 겨울 · 에어컨 · 빙수 |
| 둥근 것 | 공 · 달 · 동전 · 도넛 · 지구 · 반지 |
| 하늘을 남 | 새 · 비행기 · 구름 · 연 · 드론 · 나비 |
| 빠른 것 | 치타 · 자동차 · 번개 · 로켓 · 총알 · 바람 |
| 시끄러운 것 | 천둥 · 폭죽 · 알람 · 드럼 · 사이렌 · 코골이 |
| 물에 뜸 | 배 · 오리 · 튜브 · 나뭇잎 · 얼음 · 비누방울 |
| 밤에 봄 | 별 · 달 · 반딧불 · 가로등 · 올빼미 · 불꽃 |

- **유사군의 묘미:** 한 단어가 **여러 클러스터에 걸침**(아이스크림=단맛+차가운 것, 얼음=차가운 것+물에 뜸, 달=둥근 것+밤에 봄). 단서를 더 애매하게 만들어 은폐·추리를 깊게 함.
- 보드 예(4×4): 바다생물 4장(참치·연어·고등어·문어) + 단맛 3장(초콜릿·꿀·아이스크림) + 분산 미끼 9장(공·별·알람 등). 내 카드가 "연어"면 "바다"·"회"·"분홍" 단서가 참치·고등어에도 걸려 나를 못 특정하게 함.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                              |
| --- | --------------- | ----------------------------------------------------- |
| 1   | **로비 / 매칭** | 2~4인 매칭, 방 생성, 보드 크기(4×4/5×5) 설정           |
| 2   | **대기 / 준비** | 시드·인원·규칙 표시, 준비 완료                         |
| 3   | **카드 배정**   | 보드 전 카드 공개 + **내 카드 하이라이트**(본인만)     |
| 4   | **게임 메인**   | 공유 보드 + 순번 + 단서 입력 + 단서 로그               |
| 5   | **지목**        | 남은 상대별 카드 지정 UI + 확정                        |
| 6   | **탈락/판정 연출** | 오답 시 카드 공개·탈락 알림 / 전원 정답 시 승리 연출  |
| 7   | **결과**        | 승자·각자 카드 공개, 재시작                            |
| 8   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                           |

### 게임 메인(4번) 구성 요소

- **공유 단어 보드** — 4×4/5×5 격자, 전 카드 앞면. 내 카드만 하이라이트(내 화면), 탈락자 카드는 전원에게 공개 표시.
- **순번·단서 입력** — 현재 차례 강조, 짧은 텍스트 단서, 제한시간, 반복 방지 안내.
- **단서 로그** — 누가 언제 뭐라 흘렸는지(추리 근거, 플레이어별 정렬).
- **지목 UI** — 남은 상대 각각에 대해 보드 카드 1장씩 지정 후 [전원 확정].

### 서버/로직이 처리할 것

- **보드 생성기** — 유사군 클러스터 2~3개 + 분산 미끼로 16/25장 구성(시드 기반, 유사군 비율 준수).
- **배정 엔진** — 인원수만큼 보드 카드 중복 없이 랜덤 배정, **각 카드는 본인에게만 전달**(치트 방지). 배정은 유사군 안에서.
- **지목 판정** — 지목 세트 vs 실제 배정 비교 → 전원 일치면 승리, 아니면 지목자 탈락(단순 비교, AI 불필요).
- **턴·생존 관리** — 순번 교대, 탈락 처리·브로드캐스트, 최후 1인 판정, 종료.

> **AI 불필요 근거:** 시스템은 단서의 의미를 판단하지 않는다. 단서 생성·해석은 전부 사람이 하고(코드네임과 동일), 시스템은 **작은 유사군 뱅크에서 보드 구성 + 카드 배정 + 지목 일치 비교**만 함. 뱅크는 재사용형(소모 아님)이라 소량으로 성립.

### 통신

- **턴마다: 단서 텍스트 1건(각자→전원)** 또는 **지목 세트 1건(지목자→호스트) + 판정 브로드캐스트 1건.** → 초경량. 각자 배정 카드는 본인에게만, 실제 매핑은 호스트/서버가 보관(치트 방지), 탈락·승리 시점에만 공개.

## 라인업에서의 위치
