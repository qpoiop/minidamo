# 냥말 블러핑 (가칭) — 기획 정리서

> 2~6인 심리·추리 대전. 모두가 같은 **9장 단어판**을 본다. 시민들만 그 중 **숨은 정답 단어**를 알고, 라이어 한 명만 모른다. 돌아가며 정답과 연결된 **단서 한 마디**를 내는데, 판의 절반은 서로 뜻이 겹치는 **유사군**이라 단서 하나로는 정답이 콕 집히지 않는다. 시민은 "아는 티는 내되 라이어에겐 안 들키게", 라이어는 "모르면서 아는 척". 코드네임식 단어판에 스파이폴의 정체 추리를 얹었다.

_가칭 후보: 냥말 블러핑 / 숨은말 냥 / 아는척냥_
_(연역·귀납 추리가 '정보를 정직하게 모으는' 게임이라면, 이건 '아는 티와 모르는 티 사이에서 줄타기하는' 심리 추리. 생선 도둑이 순수 블러핑이라면 이건 블러핑+공유보드 추리)_

---

## A. 게임 내 가이드 (플레이어용 · 짧은 버전)

### 한 줄 요약

> 9장 중 **숨은 정답 단어**가 있다. 시민은 아는 티를 슬쩍, 라이어는 모르면서 아는 척. 라이어를 찾아내거나, 라이어면 정답을 알아맞혀라.

### 화면

- **공유 단어판**(9장 카드 격자)을 전원이 함께 본다.
- 정답 단어는 **시민에게만** 하이라이트로 보이고, **라이어에겐 안 보인다.**
- 9장 중 **절반쯤은 서로 뜻이 겹치는 유사군**(예: 참치·연어·고등어)이라 단서 하나로는 잘 안 좁혀진다.

### 역할 (매 판 랜덤)

- **시민(다수):** 정답을 안다. 정답과 연결된 단서를 내되 **너무 대놓고는 금지**.
- **라이어(1명):** 정답을 모른다. 남들 단서를 듣고 아는 척 단서를 지어내며, 속으로 정답을 추리한다.

### 진행

1. 순서대로 **단서 한 마디씩**(단어 or 짧은 구). 정답과 연결되지만 유사군 덕에 여러 카드에 걸친다.
2. 이걸 **2바퀴** 돈다(단서가 쌓일수록 정답이 좁혀짐).
3. **지목:** 전원 동시에 "라이어라고 생각하는 사람" 손가락질.
4. **정답 맞추기:** 라이어가 9장 중 정답이라 생각하는 카드 1장 선택.

### 승패

| 상황 | 결과 |
| --- | --- |
| 다수가 라이어를 **정확히 지목** + 라이어가 정답 **못 맞춤** | **시민 승** |
| 라이어가 **안 들킴**(지목 실패) | **라이어 승** |
| 라이어가 **정답 카드 맞춤** | **라이어 승**(들켜도 역전) |

### 핵심 감각

- 시민: 정답을 아는 걸 증명하되, 라이어에게 정답을 알려주면 안 됨 → **적당히 애매하게.**
- 라이어: 남 단서에서 공통분모를 읽어 정답을 좁히고, 자기 단서는 유사군에 묻어 안 튀게.
- 유사군이 절반이라 "이 단서는 이 카드다"가 안 되니, **말투·타이밍·미묘한 확신**을 읽는 싸움이 된다.

## B. 전체 규칙 (구현 기준 · 상세)

### 세팅

- 인원: **2~6인**(권장 4~6). 2인은 아래 **듀얼 모드**로 별도 진행.
- 시드 기반으로 단어판 9장·정답·역할을 결정(공정성·재접속).
- 단어판 9장 = **유사군 카드 4~5장 + 분산 카드 4~5장** 혼합(아래 유사군 뱅크 참고).
- 정답 1장은 **유사군 안에서** 뽑는 걸 기본으로(그래야 단서가 겹쳐 재밌음). 방 옵션으로 "분산 정답"도 가능.

### 라운드 진행 (3~6인 · 라이어 발각 모드)

1. **역할 배정:** 시드로 라이어 1명 지정. 시민 전원은 정답 하이라이트를 봄, 라이어는 못 봄.
2. **단서 라운드(2바퀴):** 순서대로 각자 단서 한 마디. 규칙:
   - 정답과 **연결**되어야 함(시민 자율 준수).
   - **정답 단어 자체·그 일부·직역**은 금지("참치"가 정답인데 "참치"·"tuna"·"캔 속 생선" 류 금지).
   - 앞사람 단서를 **그대로 복창** 금지(변형·발전은 허용).
3. **지목 단계:** 전원 동시에 라이어 후보 1명 지목. 최다 득표자가 "지목된 라이어".
4. **정답 단계:** 실제 라이어가 9장 중 1장을 **정답으로 지목**.
5. **판정:**
   - 실제 라이어 = 최다 득표 → **라이어 발각**.
   - 라이어의 정답 카드 = 실제 정답 → **라이어 정답 성공**.
6. **승패 산정**(A 표) → 점수 반영 → 다음 판 새 역할·새 판.

### 왜 유사군이 절반이어야 하나 (핵심 설계)

- 유사군이 없으면 단서 하나가 정답을 콕 집어버려 → 라이어가 즉시 정답을 알거나, 시민이 정답을 그대로 노출.
- 절반이 유사군이면 "바다"라는 단서가 참치·연어·고등어 **3장에 동시에 걸려** 정답이 안 좁혀짐 → 시민은 안전하게 아는 티를 내고, 라이어도 묻어갈 수 있음.
- 그래서 단서 1건이 아니라 **여러 단서의 교집합**으로만 정답이 드러남 → 라이어는 그 교집합을 읽어야 하고, 시민은 교집합을 너무 빨리 완성하지 않게 조절. 이게 게임의 두뇌 축.

### 2인 듀얼 모드 (좁히기 레이스)

3인 미만은 "라이어 색출"이 성립 안 되므로 구조를 바꾼다.

- 역할: **출제냥(정답 앎)** vs **탐정냥(정답 모름)**. 매 세트 교대.
- 진행:
  1. 출제냥이 **단서를 한 개씩 순차 공개**. 각 단서는 **정답에 대해 참**이어야 하고, 유사군 덕에 처음엔 여러 카드에 걸침("바다와 친해" → 참치·연어·고등어).
  2. 단서가 쌓일수록 후보가 **좁혀짐**.
  3. 탐정냥은 **아무 때나 락인(정답 확정)** 가능.
- 점수(리스크·리워드):
  - 적은 단서에서 **맞게 락인**할수록 고득점(1번째 단서 3점 / 2번째 2점 / 3번째 이후 1점).
  - **틀리게 락인**하면 그 세트 0점 + 출제냥이 보너스 1점.
  - 출제냥은 **단서를 애매하게** 낼수록(탐정이 늦게 맞출수록) 유리하지만, **거짓 단서(정답에 거짓)**를 내면 발각 시 패널티 → 정직 속의 줄타기.
- 운빨 방지 장치:
  - 유사군이 있어 초반 락인은 **도박**(같은 군 3장 중 1/3) → 신중히 단서를 더 볼지, 위험을 감수할지 판단.
  - 출제냥도 점수를 먹으므로 **양쪽이 능동적**(단서 애매하게 조절 vs 조기 락인 타이밍).
  - 세트 교대라 출제·탐정을 번갈아 → 단서 설계력과 추리력 **둘 다** 필요.

### 단서 규칙 (반칙 방지 · 자율 + 명시 금칙)

- 정답 단어 그 자체·부분·직역·자명한 동의어 금지.
- 숫자로 카드 위치 지정 금지("3번째 카드").
- 시스템은 의미 검증을 못 하므로(AI 없음) **코드네임처럼 자율 준수 + 신고**. 위반 신고 시 해당 판 무효/재출제.

### 정보 공개 범위

- **공개:** 9장 단어판(전원), 각자 낸 단서 로그, 지목 결과, 최종 정답.
- **비공개:** 정답 하이라이트(시민만), 누가 라이어인지(판정 전까지), 각자 속마음.

## C. 밸런싱 확정값 (시작값 · 프로토타입으로 미세조정)

1. **단어판 크기** → **9장**(3×3). 코드네임 감성 + 한눈에 파악. (인원 많아도 9 유지, 12장은 방 옵션)
2. **유사군 비율** → 9장 중 **유사군 4~5장**(같은 뜻범위) + **분산 4~5장**. 정답은 기본 유사군 안에서 추출.
3. **라이어 수** → 5인까지 **1명**, 6인은 방 옵션으로 **2명(라이어끼리 서로 모름)**.
4. **단서 바퀴 수** → **2바퀴**(인원×2 단서). 정보가 쌓이되 정답이 완전히 드러나기 직전에서 끊김. 방 옵션 1~3바퀴.
5. **단서 제한시간** → 1인당 **20초**. 초과 시 자동 패스(그 판 단서 없음 = 의심 유발).
6. **지목 처리** → 동시 지목, 최다 득표. **동표면 라이어 미발각**(시민 불리, 확실히 몰아야 함).
7. **정답 뱅크** → **유사군 클러스터 사전**(아래). 짧은 클러스터 리스트만으로 수백 판 조합. 소모형 아님(재사용).
8. **매치** → 기본 **3판 2선승**(판마다 역할·판 재배정). 협력 누적전도 방 옵션.
9. **동점 처리** → 세트 동점 시 서든데스 1판(라이어 발각+정답 여부로 판정).

> 2·4는 실측 핵심 — "유사군을 몇 장 섞어야 정답이 라운드 끝에 겨우 좁혀지는지 / 2바퀴가 적당한지" 재서 유사군 비율·바퀴 수를 맞춘다.

### 유사군 클러스터 사전 (예시 · 재사용 뱅크)

시스템은 아래처럼 **뜻범위가 겹치는 단어 묶음**들을 들고 있다가, 한 클러스터에서 몇 장 + 다른 데서 분산 몇 장을 뽑아 9장을 구성한다. (짧은 리스트 → 조합으로 대량 생성, AI 불필요)

| 클러스터 | 겹치는 단어들(유사군) |
| --- | --- |
| 바다생물 | 참치 · 연어 · 고등어 · 문어 · 새우 · 조개 |
| 단맛 | 초콜릿 · 사탕 · 꿀 · 아이스크림 · 케이크 · 마카롱 |
| 빨간 것 | 사과 · 딸기 · 토마토 · 고추 · 장미 · 소방차 |
| 차가운 것 | 얼음 · 눈 · 냉장고 · 겨울 · 에어컨 · 빙수 |
| 둥근 것 | 공 · 달 · 동전 · 도넛 · 지구 · 반지 |
| 하늘을 남 | 새 · 비행기 · 구름 · 연 · 드론 · 나비 |
| 빠른 것 | 치타 · 자동차 · 번개 · 로켓 · 총알 · 바람 |
| 시끄러운 것 | 천둥 · 폭죽 · 알람 · 드럼 · 사이렌 · 코골이 |
| 물에 뜸 | 배 · 오리 · 튜브 · 나뭇잎 · 얼음 · 비누방울 |
| 밤에 봄 | 별 · 달 · 반딧불 · 가로등 · 올빼미 · 불꽃 |

- **유사군의 묘미:** 한 단어가 **여러 클러스터에 걸침**(아이스크림=단맛+차가운 것, 얼음=차가운 것+물에 뜸, 달=둥근 것+밤에 봄). 이게 단서를 더 애매하게 만들어 게임을 깊게 함.
- 9장 구성 예: 바다생물 3장(참치·연어·고등어) + 분산 6장(사과·공·별·알람·비행기·눈). 정답이 "연어"면 "바다"·"회"·"분홍" 단서가 참치·고등어에도 걸려 라이어를 헷갈리게 함.

## D. 구현에 필요한 화면 & 시스템

### 화면 목록

| #   | 화면            | 핵심 요소                                              |
| --- | --------------- | ----------------------------------------------------- |
| 1   | **로비 / 매칭** | 2~6인 매칭, 방 생성, 인원·모드·유사군 비율 설정        |
| 2   | **대기 / 준비** | 시드·인원·역할 규칙 표시, 준비 완료                    |
| 3   | **역할 확인**   | 시민=정답 하이라이트 / 라이어=하이라이트 없음(본인만)  |
| 4   | **단서 라운드** | 공유 9장 판 + 순번 + 단서 입력 + 단서 로그             |
| 5   | **지목**        | 라이어 후보 동시 지목 UI                               |
| 6   | **정답·판정**   | 라이어 정답 선택 + 정답 공개 + 발각/성공 연출          |
| 7   | **결과**        | 승패·점수, 세트 스코어, 재시작                         |
| 8   | **가이드/규칙** | 위 A 섹션 (인게임 상시 열람)                           |

### 게임 메인 구성 요소

- **공유 단어판** — 9장 격자, 시민에게만 정답 하이라이트(라이어 화면엔 미표시).
- **순번·단서 입력** — 현재 차례 강조, 짧은 텍스트 단서, 제한시간.
- **단서 로그** — 지금까지 누가 뭐라 했는지(심리전 근거).
- **지목 UI** — 플레이어 아바타 중 라이어 후보 선택.
- **정답 선택 UI** — 라이어 전용, 9장 중 1장.

### 서버/로직이 처리할 것

- **단어판 생성기** — 유사군 클러스터 사전에서 유사군 N장 + 분산 M장 뽑아 9장 구성(시드 기반, 유효 비율 준수).
- **역할·정답 배정** — 라이어 지정, 정답 카드 선정(시민에게만 전달, 라이어에겐 미전달 = 치트 방지).
- **지목 집계** — 동시 지목 → 최다 득표 계산.
- **판정 엔진** — 라이어 발각 여부 + 라이어 정답 여부 → 승패 산출(단순 비교, AI 불필요).
- **라운드/매치 관리** — 역할 로테이션, 세트 점수, 승리 판정.

> **AI 불필요 근거:** 시스템은 단서의 의미를 판단하지 않는다. 단서 생성·해석은 전부 사람이 하고(코드네임과 동일), 시스템은 **작은 유사군 뱅크에서 카드 뽑기 + 역할/정답 배정 + 지목·정답 일치 비교**만 함. 뱅크는 재사용형(소모 아님)이라 소량으로 성립.

### 통신

- **라운드당: 단서 텍스트 1건(각자→전원) + 지목 1건(각자→호스트) + 정답·판정 브로드캐스트 1건.** → 초경량. 정답 카드는 시민에게만 전달, 라이어에겐 판정 시점에 공개(치트 방지 위해 호스트/서버 보관).

## 라인업에서의 위치

- 1번 모순(연역) · 2번 냥호(귀납) · 3번 우다다(순발력) · 4번 냥탈출(협동) · 냥파장(감각 캘리브레이션)
- **신규 냥말 블러핑** = **블러핑+공유보드 추리** (2~6인) ← 생선 도둑(순수 블러핑)과 추리 2종(정직한 정보 수집)의 **사이**. "아는 티 vs 모르는 티" 줄타기라는 또 다른 뇌. 유사군 단어판이라 소수(2인 듀얼)부터 파티(6인 라이어 색출)까지 커버.
- 공통: 가벼운 통신(단서 1줄 + 지목 1개), 카드 격자라 Canvas 불필요, HTML/CSS로 고퀄 가능. **AI 없이 사람이 단서 생성 + 작은 유사군 뱅크**로 성립.
