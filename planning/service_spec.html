1. 서비스 개요

minidamo는 모바일 PWA(Progressive Web App)를 기반으로 한 2인용 근거리 P2P 미니게임 플랫폼입니다. 앱 스토어를 통하지 않고 즉시 홈 화면에 웹앱 형태로 추가해 오프라인 캐싱 및 백그라운드 웹 푸시 알림을 지원받아 설치형 네이티브 앱과 동일한 유저 플로우를 완성합니다.

핵심 비전: "GPS 근거리 방 탐색으로 상대방과 탭 한 번에 매칭되고 끊김 없는 실시간 미니게임을 보장하는 모바일 PWA 서비스"

Target User

  • 현실에서 마주 앉아 가벼운 내기나 오락을 원하는 사용자 (친구, 연인, 동료)
  • 설치형 게임 앱 다운로드 및 업데이트가 귀찮은 모바일 라이트 유저
  • 오프라인이나 불안정한 모바일 기기 네트워크 환경에서도 끊김 없는 연결을 원하는 사용자

Core Value

  • 네이티브 앱급 접근: PWA 추가 설치 지원, 서비스 워커 캐싱
  • 서버 부하 최소화: WebRTC P2P 직송 기반의 초저지연 상태 관리
  • 지능형 근거리 탐색: 위도/경도 연산 필터링으로 20m 이내 매칭 구현

2. GPS 기반 근거리 P2P 연결 및 예외 복구 정책

브라우저 Sandbox 보안 규정상 블루투스 직접 스캔 등이 제한되므로, Geolocation API(위도/경도)와 시그널링 웹소켓을 혼합하여 구현합니다.

1

방 개설 및 GPS 좌표 등록 (Host)

호스트가 게임 방을 개설하면 브라우저 GPS로 현재 위도/경도를 조회하여 호스트의 Peer ID와 함께 시그널링 서버에 일시 전송합니다.

2

주변 20m 이내 방 필터링 (Guest)

게스트가 "주변 참가" 버튼을 누르면 게스트의 현재 위도/경도를 전송하고, 서버는 하버사인 공식(Haversine Formula)을 사용해 반경 20m 이내 방 목록만 추려서 보여줍니다.

3

탭 매칭 및 WebRTC 연결

게스트가 목록에서 방을 터치하면 서버가 두 피어의 ID를 기반으로 핸드셰이크를 처리하고, 다이렉트 WebRTC DataChannel을 열어 direct P2P 망을 활성화합니다.

4

실시간 거리 감시 및 이탈 제어

게임 중 주기적으로 기기의 GPS 변화값과 WebRTC RTT(왕복 지연시간)를 모니터링합니다. 연결 상태에 맞게 다음과 같이 대응합니다.

⚠️ 경고 단계 (거리 멀어짐)

물리 거리가 25m 이상으로 감지되거나 일시적인 네트워크 불량으로 지연이 심해지는 경우:

  • 화면 상단에 "상대방과의 거리가 멀어졌습니다. 연결이 불안정할 수 있습니다." 노출.
  • 게임 진행은 끊지 않고 백그라운드 재연결 프로토콜 상시 작동.

🛑 단절 및 재연결 단계

사용자 간 전파 간섭 등으로 WebRTC 연결이 완전히 소멸될 경우:

  • 게임은 일시정지(Pause)되며 중앙에 "재연결 대기 중 (5초)" 스톱워치 팝업.
  • 5초 내로 복귀 시 기존 스코어와 보드판 그대로 게임 자동 이어서 재개.
  • 5초 초과 시 "상대방 이탈로 연결 끊김" 알림 모달 후 대기방 또는 메인으로 자동 탈출.

3. PWA (Progressive Web App) 스펙 및 푸시 알림 정책

설치 가능성, 업데이트 신속성, 사용자 리인게이지먼트를 위해 설계된 PWA 세부 정책입니다.

설치 및 디스플레이 (Manifest)

  • 앱 설치 배너: 메인 화면 상단 및 설정에 "홈 화면에 앱 추가" 버튼 제공.
  • 디스플레이 모드: standalone 설정으로 브라우저 주소창, 뒤로가기 버튼 등을 감춰 풀스크린 앱처럼 노출.
  • 부팅 속도: 스플래시 화면 노출 시간 동안 프리캐싱된 자산을 불러와 앱 시작 속도를 0.2초 이내로 확보.

서비스 워커 & 캐시 라이프사이클

  • 캐시 우선(Cache-First): 게임 UI 컴포넌트, 배경음악, 효과음, Vanilla CSS 파일을 로컬에 정적 프리캐싱하여 오프라인에서도 작동 보장.
  • 무중단 업데이트: 새 빌드가 배포되면 서비스 워커가 백그라운드에서 다운로드 후 메인 화면에 "새 버전 설치 가능 - 업데이트 버튼" 팝업 노출. 터치 시 즉각 릴로드 적용.

웹 푸시 알림 (Web Push Notification) 정책: iOS/Android 네티 알림 규격 연동. 사용자가 푸시 수신 동의 시, 브라우저가 꺼진 백그라운드 상태에서도 "초대 알림"을 수신할 수 있도록 Service Worker의 push 리스너와 Notification API를 바인딩합니다.

4. 수록 미니게임 상세 룰 설계

턴제 동기화 테스트 및 실시간 패킷 전송 검증용 기본 수록 게임 규칙입니다.

1. 틱택토 (Tic-Tac-Toe)

  • 보드 판: 3x3 그리드 형태.
  • 선후공 결정: 방장(Host)이 선공(O), 참가자(Guest)가 후공(X)을 잡고 진행.
  • 승리 조건: 가로, 세로, 대각선 중 한 줄을 먼저 일치시키는 플레이어 승리.
  • 세부 규칙: 3판 2선승제 설정 가능. 제한시간 턴당 15초 초과 시 패배.

2. 미니 탁구 (Ping Pong)

  • 경기장 Layout: 뷰포트 전체 높이에 맞춘 세로형 테이블 UI.
  • 시점 보정: 양쪽 화면 모두 자신의 패들이 하단, 상대방 패들이 상단에 렌더링되도록 3D/2D 대칭 투영 렌더링.
  • 인터랙션: 스마트폰 하단을 손가락으로 드래그해 패들 조작.
  • P2P 연동: 호스트의 기기에서 물리 엔진 연산을 총괄(Host Authority)하며 게스트로 좌표 동기화 패킷 전송.
